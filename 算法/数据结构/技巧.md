# 一.枚举
## 1.枚举右，维护左
对于 双变量问题，例如两数之和 $a_i​+a _j=t$，可以枚举右边的 $a _j$，转换成 单变量问题也就是在 $a_j$左边查找是否有$a_i​=t−a_j$​，这可以用哈希表维护。
我把这个技巧叫做 枚举右，维护左。

### 1.1例题：
#### 例1：两数之和
#hot100 [两数之和](https://leetcode.cn/problems/two-sum/description/)
![[Pasted image 20260422140533.png|411]]
```java
class Solution {

    public int[] twoSum(int[] nums, int target) {
        Map<Integer,Integer> map=new HashMap<>();
        int n=nums.length;
        for(int i=0;i<n;i++){
            if(map.containsKey(target-nums[i]))
                return new int[]{i,map.get(target-nums[i])};
            map.put(nums[i],i);
        }
        return null;
    }
}
```

#### 例2：买卖股票最佳时期
#hot100 [买卖股票最佳时期](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/description/)
![[Pasted image 20260422141732.png|405]]
思路：
这题别想复杂了，只能买一次卖一次，对于每个右(卖)price，找到左边最低价(low)。price-low即为固定卖天所能获得的最高利润。枚举右，得到的最大price-low即为所得最大利益。
```java
class Solution {
    public int maxProfit(int[] prices) {
        int ans=0;
        int low=Integer.MAX_VALUE;
        for(int price:prices){
            ans=Math.max(ans,price-low);
            low=Math.min(low,price);
        }
        return ans;
    }
}
```


## 2.枚举中间
对于有三个或者四个变量的问题，枚举中间的变量往往更好算。

为什么？比如问题有三个下标，需要满足 $0≤i<j<k<n$，对比一下：

枚举 i，后续计算中还需保证 j<k。
枚举 j，那么 i 和 k 自动被 j 隔开，互相独立，后续计算中无需关心 i 和 k 的位置关系。
所以枚举中间的变量更简单。

### 2.1例题：
#### 例1：元素和最小的山形三元组
[元素和最小的山形三元组](https://leetcode.cn/problems/minimum-sum-of-mountain-triplets-ii/description/)
![[Pasted image 20260422150313.png|438]]
```java
class Solution {
    public int minimumSum(int[] nums) {
        int n=nums.length;
        int[] left=new int[n];//记录j左边的最小值
        int[] right=new int[n];//统计j右边的最大值
        left[0]=Integer.MAX_VALUE;
        for(int i=1;i<n;i++){
            left[i]=Math.min(left[i-1],nums[i-1]);
        }
        right[n-1]=Integer.MAX_VALUE;
        for(int i=n-2;i>=0;i--){
            right[i]=Math.min(right[i+1],nums[i+1]);
        }
        int ans=Integer.MAX_VALUE;
        for(int i=0;i<n;i++){
	        //满足山形才更新答案
            if(left[i]<nums[i]&&nums[i]>right[i])
                ans=Math.min(ans,left[i]+nums[i]+right[i]);
        }
        return ans==Integer.MAX_VALUE?-1:ans;
    }
}
```

#### 例2：统计特殊三元组
[统计特殊三元组](https://leetcode.cn/problems/count-special-triplets/description/)
![[Pasted image 20260422150741.png|386]]
```java
class Solution {
    public int specialTriplets(int[] nums) {
        long ans=0;
        int n=nums.length;
        Map<Integer,Integer> pre=new HashMap<>(n);//记录j前面的nums
        Map<Integer,Integer> post=new HashMap<>(n);//记录j后面的nums
        for(int i=1;i<n;i++){
            post.merge(nums[i],1,Integer::sum);
        }
        pre.put(nums[0],1);
        //只用两次遍历：第二次遍历同时维护pre.
        for(int i=1;i<n-1;i++){
            post.merge(nums[i],-1,Integer::sum);
            //cnt1和cnt2要用long,不然ans+=cnt1*cnt2等价于
            //ans=(long)(cnt1*cnt2),cnt1*cnt2如果是int时会溢出，溢出后再转成long导致结果不正确
            long cnt1=pre.getOrDefault(nums[i]*2,0);
            long cnt2=post.getOrDefault(nums[i]*2,0);
            ans+=cnt1*cnt2;
            pre.merge(nums[i],1,Integer::sum);
        }
        return (int)(ans%1000000007);
    }
}
```

### 3.1左上-右下对角线
#### 3.1.1模板
m* n 矩阵
注意到每条对角线都有k=i-j，k为定值。遍历k的取值范围，固定i，即可求j（也可以固定j）
//记不住就带几个数试试
k从最小到最大：对角线从右上到左下
k从最大到最小：对角线从左下到右上

可以在遍历过程中对j判断。
也可以对每个k，判断j最大最小值。(推荐用这种，因为这样可以直接知道对角线元素个数，便于解题时创建数组/集合)
```java
class Solution {
    public ... findDiagonalOrder (int[][] grid) {
        int m=grid.length;
        int n=grid[0].length;
        //k=i-j
        //从右上到左下，从左下到右上反之
        for(int k=0-(n-1);k<(m-1)-0;k++){
	        //j=i-k
	        int minJ=Math.max(0-k,0);
	        int maxJ=Math.min(m-1-k,n-1);

			//从对角线左上到右下，右下到左上反之
			for(int j=minJ;j<=maxJ;j++){
				//这里不用判断i是否在范围内，因为j合法，说明i一定也合法
				int i=j+k;
				//...完成题目要求。
			}
		}
    }

}
```

```java
class Solution {
    public int[][] sortMatrix(int[][] grid) {
        int m=grid.length;
        //k=i-j
        for(int k=1-m;k<=m-1;k++){
	        //j=i-k
			int minJ=Math.max(0-k,0);
			int maxJ=Math.min(m-1-k,m-1);
			//为什么要Integer?
			//comparator要接收泛型，泛型要引用类型，否则无法调用比较器比较
			//为什么要确定record大小？
			//因为不确定大小剩下的会填null,导致comparator比较时报空指针错误
			//当然也可以不确定大小，用List来记录。
			Integer[] record=new Integer[maxJ-minJ+1];
			int cnt=0
            for(int j=minJ;j<=maxJ;j++){
	            int i=k+j; 
	            record[cnt++]=grid[i][j];
            }
            if(k<0)
	            Arrays.sort(record);
	        else
		        Arrays.sort(record,(o1,o2)->o2-o1);
            cnt=0;
            for(int j=minJ;i<=maxJ;j++){
	            int i=j+k;
                grid[i][j]=record[cnt++];
            }
        }
        return grid;
    }
}
```
### 3.2右上-左下遍历
#### 3.2.1模板
和左上-右下类似，只不过每个对角线i+j为定值，至于对角线从左上到右下还是右下到左上可以自己带几个数试下。对角线内的顺序也可以带几个数试试。
```java
class Solution {
    public ... findDiagonalOrder (int[][] grid) {
        int m=grid.length;
        int n=grid[0].length;
        //k=i+j
        //从左上到右下，从右下到左上反之
        for(int k=0;k<=m+n-2;k++){
	        //j=k-i
	        int minJ=Math.max(k-m+1,0);
	        int maxJ=Math.min(k,n-1);
	        //对角线长度：maxJ-minJ+1
            //可以选择遍历i，也可以选择遍历j
			//but既然都把j范围算出来了，为什么不遍历j？
			//从对角线左下到右上，右上到左下反之
			for(int j=minJ;j<=maxJ;j++){
				//这里不用判断i是否在范围内，因为j合法，说明i一定也合法
				int i=k-j;
				//...完成题目要求。
			}
		}
    }

}
```

##### 例1：对角线遍历
[对角线遍历](https://leetcode.cn/problems/diagonal-traverse/)

```java
class Solution {
    public int[] findDiagonalOrder(int[][] mat) {
        //k=i+j
        int m=mat.length;
        int n=mat[0].length;
        int[] ans=new int[m*n];
        int cnt=0;
        //对角线从左上到右下
        for(int k=0;k<m+n-1;){
            //j=k-i
            int minJ=Math.max(k-m+1,0);
            int maxJ=Math.min(k,n-1);
            //左下到右上
            for(int j=minJ;j<=maxJ;j++){
                //i=k-j
                int i=k-j;
                ans[cnt++]=mat[i][j];
            }
            k++;
            minJ=Math.max(k-m+1,0);
            maxJ=Math.min(k,n-1);
            //右上到左下
            for(int j=maxJ;j>=minJ;j--){
                //i=k-j
                int i=k-j;
                ans[cnt++]=mat[i][j];
            }
            k++;
        }
        return ans;
    }
}
```
# 二.前缀和
## 1.基础
**模板**
```java
class NumArray {
    int[] nums;
    //presum[i] 定义为[0,i)的和（不包括自身），特殊的presum[0]=0
    int[] presum;
    
    public NumArray(int[] nums) {
        this.nums=nums;
        int n=nums.length;
        presum=new int[n+1];
        presum[0]=0;
        for(int i=0;i<n;i++){
            presum[i+1]=presum[i]+nums[i];
        }
    }
    //[left,right]的和等价于[0~right]-[0~left-1]=presum(right+1)-presum(left)；
    public int sumRange(int left, int right) {
        return presum[right+1]-presum[left];
    }
}
```
## 2.前缀和与哈希表（HashMap)
通过枚举右维护左，用哈希表来保存左边各前缀和的个数，即可得到固定右端点的任意子数组和的个数。
### 例题
#### 例1：和为K的子数组
#hot100 [和为K的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/description/)
![[Pasted image 20260424143744.png|408]]
思路：用前缀和+哈希表，枚举子数组的右端点，对于固定右端点(i)的子数组，我们需要其和为k，说明我们还需要前面有和为pre[i+1]-k的子数组。用一个哈希表维护左边的前缀和即可。
为什么不用移动窗口：nums可以为负数。
```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        int n=nums.length;
        int[] pre=new int[n+1];
        pre[0]=0;
        for(int i=0;i<n;i++)
            pre[i+1]=pre[i]+nums[i];
        int ans=0;
        Map<Integer,Integer> map=new HashMap<>();
        map.put(0,1);
        for(int i=0;i<n;i++){
            ans+=map.getOrDefault(pre[i+1]-k,0);
            map.merge(pre[i+1],1,Integer::sum);
        }
        return ans;
    }

}
```
