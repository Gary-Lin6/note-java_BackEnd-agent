### 例2：字符串解码
#hot100  [字符串解码](https://leetcode.cn/problems/decode-string/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260424155452.png|415]]
思路：思路就是把非“]”的都入栈，直到遇到“]"后，弹出逐渐弹出栈内字母，直到遇到” \[ ",然后再弹出前面记录的数字k，将弹出的字母重复k次重新入栈。依次类推，直到结束。结束后栈内每个元素为各组（数字\[字母]）解码后的结果，再逐个弹出拼接即可。
```java
//原先解法：受限于栈每次只能弹出栈顶：所有要想在字母前拼接得用insert(0)，使得整体退化成O(n^2)
//且使用正常表达式判断，比判断单字母慢。
class Solution {
    public String decodeString(String s) {
        Deque<String> stack=new ArrayDeque<>();
        String regexInt="[0-9]+";
        String regexChar="[a-z]+";
        for(int i=0;i<s.length();i++){
            String c=s.substring(i,i+1);
            if(stack.isEmpty()){
                stack.push(c);
                continue;
            }        
            if(c.matches(regexChar)){
                if(stack.peek().matches(regexChar)){
                    String pre=stack.pop();
                    pre+=c;
                    stack.push(pre);
                }
                else
                    stack.push(c);
            }
            else if(c.matches(regexInt)){
                if(stack.peek().matches(regexInt)){
                    String pre=stack.pop();
                    pre+=c;
                    stack.push(pre);
                }
                else
                    stack.push(c);
            }
            else if(c.equals("["))
                stack.push(c);
            else if(c.equals("]")){
                StringBuilder sb=new StringBuilder();
                while(!stack.peek().equals("[")){
                    sb.insert(0,stack.pop());
                }
                stack.pop();
                int num=Integer.parseInt(stack.pop());
                for(int j=0;j<num;j++){
                    sb1.append(sb);
                }
                stack.push(sb1.toString());
            }
        }
        StringBuilder sb=new StringBuilder();
        while(!stack.isEmpty()){
            sb.insert(0,stack.pop());
        }
        return sb.toString();
    }
}
```

```java
//思考：怎么优化？
//主要瓶颈在于insert(0),而使用insert(0)的原因是把[]里的东西都塞进了栈里，要想取出来只能从尾部取。那如果我们用一个StringBuilder来记录[]的内容，当遇到]时就直接重复StringBuilder，不就不用insert(0)了吗？
//随之而来的是，如果[]嵌套怎么办？欸，遇到[]时就把StringBuilder入栈就好啦。这样里面的弹出后，再取出拼接即可。
//那此时我们可以给cur再赋予一个含义：当前已处理好的内容，遇到[前，cur要么是没遇到过[]的字符串，要么是已经处理好的字符串。入栈，等待[]来处理，[]处理完，cur再拼接已经处理好的内容。

//insert(0)解决后，下一个问题是正则表达式的问题。有没有别的办法判断呢？有的兄弟有的，用Character.isDigit判断是不是数字，用Character.isLetter判断是不是字母。

//但其实我一开始也有考虑这个，为什么没用呢？因为我的入栈逻辑是，如果是字母，判断前面是不是字母，如果是，则拼接，不是则直接入栈。如果是数字，则判断是不是数字，如果是，则拼接，如果不是，则直接入栈。因为要拼接，所以我的栈类型为String,而不是Character,所以不能用。
//但有人就要问了，欸，你遍历的时候不也是一个字母一个字母遍历吗？那对字母，也可以判断啊。是的，对单字母可以判断，但对上一个元素呢？上一个元素就不一定是单字母了。
//那要怎么解决呢？其实追根到底，是我要拼接上一个元素，为什么要拼接上一个元素？对于字母而言，其实拼不拼都无所谓，因为在[]内或最后，都会一起拼起来。主要是数字，如果不止一位，你不拼起来你就不知道它是什么。
//那为什么不把数字和字母分开呢？用一个变量专门存此时的数字情况，不就不用把数字一位位存到栈内再合起来吗？
//同样的一个数字对应的是一个[]，遇到[[]]怎么办，有两种解决方法：1是数字单独一个栈，2是还是用同一个栈。遇到[时，数字入栈
//好了，总结一下解决方案：1是用一个变量来记录已经处理好的内容，避免入栈再出栈要拼接到前面的问题
//2是用一个变量来记录num，避免因为要记录数字，而不得不选择的再判断前一个元素是字母还是数字，而引起的正则表达式判断问题。
class Solution {
    public String decodeString(String s) {
        Deque<StringBuilder> strstack=new ArrayDeque<>();
        Deque<Integer> numstack=new ArrayDeque<>();
        //当前括号内要重复的次数
        int num=0;
		//当前已处理好的字符串
        StringBuilder cur=new StringBuilder();
        for(char c:s.toCharArray()){
            if(Character.isDigit(c)){
                num=num*10+(c-'0');
            }
            else if(Character.isLetter(c)){
                cur.append(c);
            }
            else if(c=='['){
                numstack.push(num);
                strstack.push(cur);
                //重置num,cur相当于递归处理[]内的内容
                num=0;
                cur=new StringBuilder();
            }
            else{
                StringBuilder tmp=cur;
                cur=strstack.pop();
                //这里要新建一个变量，或者num用完后再清零，否则会影响后面重复次数
                int repeat=numstack.pop();
                for(int i=0;i<repeat;i++)
                    cur.append(tmp);
            }
        }
        //最后cur一定是已经处理完的字符串。
        return cur.toString();
    }
}
```

```java
//递归思路。其实栈就是模拟了递归
class Solution {
    public String decodeString(String s) {
        return decode(s.toCharArray());
    }
    //用全局变量来控制s到哪，避免了substring
    private int i = 0;
  
  //按[]拆分，每个decode s返回的是[]里的内容(未重复)，最外层相当于外面有个1[]。
    private String decode(char[] s) {
        StringBuilder res = new StringBuilder();
        int k = 0;
        while (i < s.length) {
            char c = s[i];
            i++;
            if (Character.isLetter(c)) {
                res.append(c);
            } else if (Character.isDigit(c)) {
                k = k * 10 + (c - '0');
            } else if (c == '[') { // 递
                String t = decode(s);
                res.repeat(t, k); // 把括号内的字符串重复 k 次
                k = 0; // 重置 k，若不重置，2[a]3[b] 后面的 3 会算出 k = 23
            } else { // ']' 归
                break;
            }
        }
        return res.toString();
    }
}
```

## 2.单调栈
单调栈适用于找左/右边第一个大于/小于自身的元素。

### 1.模板：以求左/右第一个比自身大的元素(下标)
```java
//理解：在栈里面的是还没有求出值的，每次出栈说明遇到第一个比他大的了，计入答案
class Solution {
    public int[][] nearestGreater(int[] nums) {
        int n=nums.length;
	    int[] left=new int[n];
		int[] right=new int[n];
       Deque<Integer> stack=new ArrayDeque<>();
       //求右边第一个比自身大的元素//没有用n表示
       for(int i=0;i<n;i++){
            while(!stack.isEmpty()&&nums[stack.peek()]<nums[i]){
				right[stack.pop()]=i；
            }
            stack.push(i);
       }
       while(!stack.isEmpty()){
            right[stack.pop()]=n;
       }
       //求左边第一个比自身大的元素//没有用-1表示
       for(int i=n-1;i>=0;i--){
            while(!stack.isEmpty()&&nums[stack.peek()]<nums[i]){
				left[stack.pop()]=i；
            }
            stack.push(i);
       }
       while(!stack.isEmpty()){
            left[stack.pop()]=-1;
       }
	   return new int[][]{left,right};
    }
}
//模板2：
//理解：栈里保存的是之前的数据，因为要求的是第一个比它大的元素，所以，维护一个单调递减的栈，因为如果该数比栈顶都大了，就没必要再和之前比栈顶都小的数比较了。如果比栈顶的数都小，说明栈顶就是第一个比它大的数，那么以前比栈顶的数也没用。
//每次进一个数，弹出栈里比它小的数，直到栈为空或遇到比它大的数。此时栈顶就是第一个比它大的数。记录答案。
//哨兵作用：避免判断栈是否为空，同一栈顶即为第一个比它大的数。
//和上一种区别，不用再在循环后在遍历一遍栈。因为每个数遍历时都能得到答案。
class Solution {
    private int[][] nearestGreater(int[] nums) {
        int n = nums.length;
        // left[i] 是 nums[i] 左侧最近的严格大于 nums[i] 的数的下标，若不存在则为 -1
        int[] left = new int[n];
        Deque<Integer> st = new ArrayDeque<>();
        st.push(-1); // 哨兵
        for (int i = 0; i < n; i++) {
            int x = nums[i];
            while (st.size() > 1 && nums[st.peek()] <= x) { // 如果求严格小于，改成 >=
                st.pop();
            }
            left[i] = st.peek();
            st.push(i);
        }

        // right[i] 是 nums[i] 右侧最近的严格大于 nums[i] 的数的下标，若不存在则为 n
        int[] right = new int[n];
        st.clear();
        st.push(n); // 哨兵
        for (int i = n - 1; i >= 0; i--) {
            int x = nums[i];
            while (st.size() > 1 && nums[st.peek()] <= x) { // 如果求严格小于，改成 >=
                st.pop();
            }
            right[i] = st.peek();
            st.push(i);
        }

        return new int[][]{left, right};
    }
}
```

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n=temperatures.length;
       int[] ans=new int[n];
       Deque<Integer> stack=new ArrayDeque<>();
       for(int i=0;i<n;i++){
            while(!stack.isEmpty()&&temperatures[stack.peek()]<temperatures[i]){
```

#### 例1：柱状图中最大的矩阵
#hot100 [柱状图中最大的矩阵](https://leetcode.cn/problems/largest-rectangle-in-histogram/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260426194319.png|399]]
思路：因为最大矩形的高一定是height其中之一，（反证法：如果不在height中，那我们可以增加高度直到触及某根柱子的顶部，宽不变，高增大，面积更大，与最大矩形矛盾）
那么我们可以遍历height，求以height为高的最大矩形。
对于每个height，最大矩形的宽为（右边第一个比它小的下标-1）-（左边第一个比它小的下标-1）+1。更新ans即可。

以下遍历次数指left，right更新整体次数（即清空stack记为一个循环，因为可以用模板2省去该循环）
**三次遍历**
思路同上
不过他们时间复杂度都是O(n)
```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        int n=heights.length;
        int[] left=new int[n];
        int[] right=new int[n];
        Deque<Integer> stack=new ArrayDeque<>();
        for(int i=0;i<n;i++){
            while(!stack.isEmpty()&&heights[stack.peek()]>heights[i])
                right[stack.pop()]=i;
            stack.push(i);
        }
        while(!stack.isEmpty()){
            right[stack.pop()]=n;
        }
        for(int i=n-1;i>=0;i--){
            while(!stack.isEmpty()&&heights[stack.peek()]>heights[i])
                left[stack.pop()]=i;
            stack.push(i);
        }
        while(!stack.isEmpty())
            left[stack.pop()]=-1;
        int ans=0;
        for(int i=0;i<n;i++){
            ans=Math.max(ans,heights[i]*(right[i]-left[i]-1));
        }
        return ans;
    }
}
```
**两次遍历**
思路：当我们求right时，每个nums[i]会弹出栈例比它大的元素，直到遇到<=它的元素，那此时的栈顶元素，不就是第一个比它小的元素吗？更新left即可
我们之前求的都是比它小的第一个元素，这里变成<=它的第一个元素，可以吗？
其实是可以的，虽然在右边的相同元素宽会变小，但是在最左边的相同元素的left,right并没有受到影响，最大面积同样可以求出来

## 1.单调队列
与单调栈类似，只不过可以取队首元素了。
如果说单调栈适用于找左边/右边第一个比自身大/小的数。
那么单调队列使用于找左边/右边（在一定范围内，不再是[0~i]）比自身大/小（队首：范围内最大/小的，队尾：第一个比自身大/小的）的数。
比单调栈要注意的是，要维护队列内的元素是在规定范围内的。
所以单调队列=滑动窗口+单调栈（能取栈底版）。

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
       int n=nums.length;
       int[] ans=new int[n-k+1];
       int cnt=0;
       Deque<Integer> q=new ArrayDeque<>();
       for(int i=0;i<n;i++){
            while(!q.isEmpty()&&nums[q.getLast()]<=nums[i])
                q.removeLast();
            q.addLast(i);
            int left=i-k+1;
            if(left<0)
                continue;
            ans[cnt++]=nums[q.getFirst()];
            if(q.getFirst()<=left)
                q.removeFirst();
       }
       return ans;
    }
}
```

```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
    //要统计nums中不同元素的个数很自然想到哈希表
        HashMap<Integer,Integer> map=new HashMap<>();
        for(int num:nums){
            map.merge(num,1,Integer::sum);
        }
        //要获取前k大的元素，那就是获取k次最大堆的堆顶
        //用一个最大堆存每个元素出现次数，但结果要求返回是元素本身，所以泛型我们可以想到用map的entry实现
        Queue<Map.Entry<Integer,Integer>> pq=new PriorityQueue<>((o1,o2)->o2.getValue()-o1.getValue());
        for(Map.Entry<Integer,Integer> entry:map.entrySet()){
            pq.offer(entry);
        }
        int[] ans=new int[k];
        for(int i=0;i<k;i++){
            Map.Entry<Integer,Integer> entry=pq.poll();
            ans[i]=entry.getKey();
        }
        return ans;
    }
}
```

```java
    //对于重排后的链表，相当于是每次从所有链表中选最小值插到尾部。
    //而所有链表的最小值，就是每个链表头节点的最小值。
    //所以将所有链表入堆，按头节点大小排序即可。
        Queue<ListNode> pq=new PriorityQueue<>((o1,o2)->o1.val-o2.val);
        for(ListNode list:lists){
            if(list!=null)
                pq.offer(list);
        }
        ListNode dummy=new ListNode(0);
        ListNode cur=dummy;
        while(!pq.isEmpty()){
            ListNode node=pq.poll();
            cur.next=node;
            cur=cur.next;
            node=node.next;
            if(node!=null)
                pq.offer(node);
        }
        return dummy.next;
    }
}
```

## 5.对顶堆
前面求第k大和第k小时，只用维护一个最大堆/最小堆即可。但如果k随着输入数增大而变化呢？
依次输入数，我们可以建一个大小为k的最小堆存当前最大的k个元素，再建一个最大堆存剩下的元素。
当k变化时，我们只要始终维护最小堆始终为最大k个数，如果k变大，我们可以从新输入的数或者最小堆堆顶拿数填入。变小只用判断新输入的数要不要放入最小堆并逐渐弹出堆顶直到个数满足。
这样就构建了一个动态大小的最大/小堆。
为什么要两个堆？因为堆大小变化时，需要之前最大/最小的元素，所以新建一个堆来保存没选的元素，方便堆大小变化。

```java
class MedianFinder {
    private PriorityQueue<Integer> minHeap;
    private PriorityQueue<Integer> maxHeap;
    //最小堆存最大的n/2个元素。最大堆存剩下的元素
    public MedianFinder() {
        this.minHeap=new PriorityQueue<>();
        this.maxHeap=new PriorityQueue<>((a,b)->b-a);
    }
    //维护最小堆要么比最大堆个数大一，要么相等
    //数列从大到小：最小堆...最小堆堆顶，最大堆堆顶...最大堆。
    //只用判断新增的数与最小堆堆顶，最大堆堆顶的大小关系，就能知道应该插到哪个堆里
    public void addNum(int num) {
        if(minHeap.isEmpty()){
            minHeap.offer(num);
            return;
        }
        else if(minHeap.size()==maxHeap.size()){
            if(num<=maxHeap.peek()){
                int tmp=maxHeap.poll();
                minHeap.offer(tmp);
                maxHeap.offer(num);
            }
            else{
                minHeap.offer(num);
            }
        }
        else if(minHeap.size()==maxHeap.size()+1){
            if(num>=minHeap.peek()){
                int tmp=minHeap.poll();
                minHeap.offer(num);
                maxHeap.offer(tmp);
            }
            else {
                maxHeap.offer(num);
            }
        }
    }
    //最小堆个数大一说明为整体为奇数，取最小堆的堆顶即为中位数
    //个数相等说明整体为偶数，取最大最小堆的堆顶平均数即为中位数
    public double findMedian() {
       if(minHeap.size()==maxHeap.size())
            return (double)(minHeap.peek()+maxHeap.peek())/2.0;
        else    
            return (double)minHeap.peek();
    }
}
```
