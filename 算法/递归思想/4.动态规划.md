# 一.入门DP
## 1.模板：从递归->记忆化递归->递推->空间优化
以最简单的爬楼梯为例：
[爬楼梯](https://leetcode.cn/problems/climbing-stairs/description/)
![[Pasted image 20260521143058.png|480]]
我们思考动态规划的题时，可以从最后一步想起。
要爬到第n阶，最后一步有两种选择，要么爬1阶，要么爬2阶。很明显，设dfs(n)：爬到第n阶时所需方法，那么dfs(n)=dfs(n-1)+dfs(n-2)；递推关系显而易见
```java
class Solution {
    public int climbStairs(int n) {
        return dfs(n);
    }
    private int dfs(int n){
    //递归边界怎么判断？可以倒推到1，2阶的时候
    //dfs(1)=dfs(0)+dfs(-1);dfs(2)=dfs(1)+dfs(0)
    //所以只用规定正确dfs(0)和dfs(1)，就不会越界。
    //显然，dfs(0):爬0阶，即不动，有一种方法。
    //dfs(1):爬1阶，有且只有一种方法。
    //综上递归边界为n<=1 return 1；
        if(n<=1)
            return 1;
        return dfs(n-1)+dfs(n-2);
    }
}
```
然后我们一提交，会发现，超时了！这是因为搜索树可以近似为一棵二叉树，树高为 O(n)，所以节点个数为 O(2^n)，遍历搜索树需要 O(2^n) 的时间。
那么怎么优化？
我们注意到，其实很多dfs值是重复的，dfs(n)=dfs(n-1)+dfs(n-2),dfs(n-1)=dfs(n-2)+dfs(n-3)，
前面求dfs(n)时已经把dfs（n-1），dfs(n-2)求了一次了，后头求dfs(n-1)又求了一次dfs(n-2)。类似的情况很多。我们只要用一个数组，记录dfs(n)对应的值，就可以实现记忆化搜索了。
```java
class Solution {
    private int[] cache;
    public int climbStairs(int n) {
        this.cache=new int[n+1];
        return dfs(n);
    }
    private int dfs(int i){
        if(i<=1)
            return 1;
        if(cache[i]!=0)
            return cache[i]; //如果cache已经记录了，说明dfs（i)已经求过了，直接复用。
        return cache[i]=dfs(i-1)+dfs(i-2); //没有则说明要求，并记录在cache[i]里
    }
}
```
进一步的，我们可以将递归改成递推。（毕竟“递”“归“两步也是要耗时间的）
那么我们可以用f[i]来代替dfs(i)。只保留归这一步，自底向上的归出dfs(n)即f[i]
```java
class Solution {
    public int climbStairs(int n) {
        int[] f=new int[n+1]; //dfs(0)-dfs(n)共n+1个元素
        //递归边界改写
        f[0]=1;
        f[1]=1;
        for(int i=2;i<=n;i++){
            f[i]=f[i-1]+f[i-2];
        }
        return f[n];
    }
}
```
此时的空间复杂度是O(n)，我们可以进一步的优化吗？
注意到f[i]=f[i-1]+f[i-2]，f[i+1]=f[i]+f[i-1]。
每次操作我们只用两个变量，f0，f1.
f0：上上个状态
f1：上个状态
f[i]=f1+f0---->此时，上上个状态f0=f1,上个状态f1=f[i]。
那么f[i+1]=f1+f0。依次类推。
最终结果就是f1
```java
class Solution {
    public int climbStairs(int n) {
        int f0=1;
        int f1=1;
        for(int i=2;i<=n;i++){
            int newF=f0+f1;
            f0=f1;
            f1=newF;
        }
        return f1;
    }
}
```
空间复杂度优化为O(1)
最后还有个矩阵快速幂优化：见[矩阵快速幂优化]([https://leetcode.cn/problems/climbing-stairs/](https://leetcode.cn/problems/climbing-stairs/solutions/2560716/jiao-ni-yi-bu-bu-si-kao-dong-tai-gui-hua-7zm1/))
## 2.爬楼梯
爬楼梯变式主要在于可以从第k阶台阶开始爬，一次可以爬t级台阶。
从第k阶台阶开始爬：说明<=k时的花费均为0；
一次可以爬t级台阶：可以用个循环计算爬1-t级台阶所需最小值。注意循环开始最少要从第0级开始爬。

为什么有的用循环有的不用？
其实没用循环的也可以改写成用循环。只不过因为没用循环的大多不用考虑边界。
比如例1，可以从第零或一级开始爬，且一次最多爬2级，那么dfs（2）=Math.min(dfs(1)+cost[1],dfs(0)+cost[0])。且dfs（1），dfs（0）都确定。可以省略能否向下判断。
而例2，因为只能从第0级开始爬，所以dfs（1），dfs（2），dfs（3）能向下递推的台阶数不同，所以需要一个循环。
### 例1：使用最小花费爬楼梯
[使用最小花费爬楼梯](https://leetcode.cn/problems/min-cost-climbing-stairs/description/)
![[Pasted image 20260523131817.png|535]]
先从记忆化递推写起：考虑函数意义，递推关系，递归边界
dfs(i):爬第i层楼梯最低花费。
显然dfs(i)=Math.min(dfs(i-1)+cost[i-1],dfs(i-2)+cost[i-2])。
递归边界：能从第0或第一阶爬起：说明i<=0时dfs（i)=0。
```java
class Solution {
    private int[] cache;
    public int minCostClimbingStairs(int[] cost) {
        int n=cost.length;
        this.cache=new int[n+1];
        Arrays.fill(cache,-1);
        return dfs(cost,n);
    }
    private int dfs(int[] cost,int i){
        if(i<=1)
            return 0;
        if(cache[i]!=-1)
            return cache[i];
        return cache[i]=Math.min(dfs(cost,i-2)+cost[i-2],dfs(cost,i-1)+cost[i-1]);
    }
}
```
改写成递推：
f[i]：到第i阶所需最低花费。
递推关系根据递推关系容易改写为：f[i]=Math.min(f[i-1]+cost[i-1],f[i-2]+cost[i-2])
初始化：f[0]，f[1]=0;
```java
class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int n=cost.length;
        int[] f=new  int[n+1];
        f[0]=0;
        f[1]=0;
        for(int i=2;i<=n;i++){
            f[i]=Math.min(f[i-1]+cost[i-1],f[i-2]+cost[i-2]);
        }
        return f[n];
    }
}
```

### 例2：爬楼梯2
[爬楼梯2](https://leetcode.cn/problems/climbing-stairs-ii/)
![[Pasted image 20260523133143.png|564]]
记忆化递推：
```java
class Solution {
    private int[] cache;
    public int climbStairs(int n, int[] costs) {
        this.cache=new int[n+1];
        Arrays.fill(cache,-1);
        return dfs(n,costs);
    }
    private int dfs(int i,int[] costs){
    //从第0阶开始爬
        if(i==0)
            return 0;
        if(cache[i]!=-1)
            return cache[i];
        int ans=Integer.MAX_VALUE;
        //一次能爬三级台阶，但要注意第i<=2时，不能爬那么多
        for(int j=1;i-j>=0&&j<=3;j++){
            ans=Math.min(ans,dfs(i-j,costs)+j*j);
        }
        return cache[i]=ans+costs[i-1];
    }
}
```
改写成递推：
```java
class Solution {
    public int climbStairs(int n, int[] costs) {
        int[] f=new int[n+1];
        f[0]=0;
        for(int i=1;i<=n;i++){
            int res=Integer.MAX_VALUE;
            for(int j=Math.max(i-3,0);j<i;j++){
                res=Math.min(res,f[j]+(i-j)*(i-j));
            }
            f[i]=res+costs[i-1];
        }
        return f[n];
    }
}
```

## 3.打家劫舍
### 例1：打家劫舍
#hot100  [打家劫舍](https://leetcode.cn/problems/house-robber/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260523140347.png]]
打家劫舍问题可以转换成从左往右或者从右往左偷：
就算从中间往两边偷，最后偷出来的最多钱也和从左往右开始偷的钱一样，所以和偷的顺序无关。

假设从左往右偷：
dfs(i):偷到第i间房时最多能偷到的钱
dfs(i)=Math.max(不抢第i间房，抢第i间房)
不抢第i间房时:dfs(i)=dfs(i-1)
抢第i间房，因为不能抢相邻的房，所以此时第i-1间房不能抢。那么前i-1间房抢的最多钱=dfs（i-2）。
综上：dfs(i)=Math.max(dfs(i-1),dfs(i-2)+cost[i]);

```java
class Solution {
    private int[] cache;
    public int rob(int[] nums) {
       int n=nums.length;
       this.cache=new int[n];
       Arrays.fill(cache,-1);
       return dfs(nums,n-1);
    }
    private int dfs(int[] nums,int i){
		//前面没房，能抢到0块钱
        if(i<0)
            return 0;
        if(cache[i]!=-1)
            return cache[i];
        return cache[i]=Math.max(dfs(nums,i-1),dfs(nums,i-2)+nums[i]);
    }
}
```
改写成递推关系：
```java
class Solution {
    public int rob(int[] nums) {
        int n=nums.length;
        //为什么这里数组长度要n+2
        //为了统一前两间房,第0间房：f[0]=Math.max(f[-1],f[-2]+nums[0])
        //所以把f数组整体往右挪了两位，总共n+2位，这样第0间房f[2]=Math.max(f[1],f[0]+nums[0]),不会数组越界。
        int[] f=new int[n+2];
        f[0]=0;
        for(int i=0;i<n;i++){
            f[i+2]=Math.max(f[i]+nums[i],f[i+1]);
        }
        return f[n+1];
    }
}
```
### 例2：打家劫舍2
[打家劫舍2](https://leetcode.cn/problems/house-robber-ii/description/)
![[Pasted image 20260525133701.png|474]]
对于环形数组。可以用两次动态规划。
分为抢第一间和不抢第一间
则将问题转化为：Math.max(偷第一家+偷第[2,n-2]家，（不偷第一家）偷第1-n-1家）。
```java
class Solution {
    public int rob(int[] nums) {
        int n=nums.length;
        return Math.max(nums[0]+robWithRange(nums,2,n-2),robWithRange(nums,1,n-1));
    }
    //偷[start,end]家
    private int robWithRange(int[] nums,int start,int end){
	    //end<start,说明没得偷
        if(end<start)
            return 0;
         //模仿打家劫舍1，整体右移两位。
        int[] f=new int[end-start+3];
        //f从[0,end-start+2],nums从[start,end]
        //f[0],f[1]:防越界
        //f[i],i∈[2,end-start+2]对应偷到nums[j],j∈[start,end]的最大值
        //j=i+start-2
        for(int i=0;i<=end-start;i++){
           f[i]=Math.max(f[i-2]+nums[i+start-2],f[i-1]);
        }
        return f[end-start+2];
    }
}
```
当然，空间优化后的代码，就不用考虑f与nums的映射关系，更容易理解。
```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        return Math.max(nums[0] + rob1(nums, 2, n - 1), rob1(nums, 1, n));
    }

    // 198. 打家劫舍
    // 偷下标在 [start, end) 中的房子
    private int rob1(int[] nums, int start, int end) {
        int f0 = 0;
        int f1 = 0;
        for (int i = start; i < end; i++) {
            int newF = Math.max(f1, f0 + nums[i]);
            f0 = f1;
            f1 = newF;
        }
        return f1;
    }
}
```
### 例3：打家劫舍5
[打家劫舍5](https://leetcode.cn/problems/house-robber-v/description/)
![[Pasted image 20260525140725.png|504]]
与普通打家劫舍区别在于，上家如果颜色不同，相邻也能偷。
那么分颜色相同或不同两类讨论即可。
```java
class Solution {
    private long[] cache;
    public long rob(int[] nums, int[] colors) {
        int n=nums.length;
        this.cache=new long[n];
        return dfs(nums,colors,n-1);
    }
    private long dfs(int[]nums,int[] colors,int i){
        if(i<0)
            return 0;
        if(cache[i]!=0)
            return cache[i];
        long res=0;
		//第0家会越界，偷到第0家最大值肯定是偷第0家。
		//可以把她归到下面那一类，亦或者前面递归边界可以加个i==0，return nums[0]；
        if(i!=0&&colors[i]!=colors[i-1])
			//i，i-1家都可以偷。
            res=dfs(nums,colors,i-1)+nums[i];
        else
            res=Math.max(dfs(nums,colors,i-1),dfs(nums,colors,i-2)+nums[i]);
        return cache[i]=res;
    }
}
```
转化成递推：
```java
class Solution {
    public long rob(int[] nums, int[] colors) {
        int n=nums.length;

            if(i!=0&&colors[i-1]!=colors[i])
                f[i+2]=f[i+1]+nums[i];
            else
                f[i+2]=Math.max(f[i+1],f[i]+nums[i]);
```

## 4.最大子数组和
1.定义状态 f[i] 表示以 a[i] 结尾的最大子数组和，不和 i 左边拼起来就是 f[i]=a[i]，和 i 左边拼起来就是 f[i]=f[i−1]+a[i]，取最大值就得到了状态转移方程 f[i]=max(f[i−1],0)+a[i]，答案为 max(f)。这个做法也叫做 Kadane 算法。
2.也可以用前缀和来做，遍历右边界，记录左边的最小前缀和，右边界的最大子数组为右边界前缀和-左边的最小前缀和。
### 例1：最大子数组和
#hot100 [最大子数组和](https://leetcode.cn/problems/maximum-subarray/description/?envType=study-plan-v2&envId=top-100-liked)
```java
class Solution {
    public int maxSubArray(int[] nums) {
        int n=nums.length;
        //f右移1位防越界
        int[] f=new int[n+1];
        //子数组不为空
        int ans=Integer.MIN_VALUE;
        for(int i=0;i<n;i++){
	        //以 a[i] 结尾的最大子数组和
            f[i+1]=Math.max(f[i],0)+nums[i];
            //更新答案
            if(f[i+1]>ans)
                ans=f[i+1];
        }
        return ans;
    }
}
```
### 例2：任意子数组和的绝对值的最大值
[任意子数组和的绝对值的最大值](https://leetcode.cn/problems/maximum-absolute-sum-of-any-subarray/description/)
![[Pasted image 20260526134727.png|589]]
与上题有两个不同之处：
1. 子数组可以为空
2. 求的是子数组和的绝对值的最大值
那么可以用两次动态规划。一次动态规划求子数组和的最大值。一次动态规划求子数组和的最小值。最后取两者绝对值的最大值即可。
当然两次动态规划可以合并在一起来求。
```java
class Solution {
    public int maxAbsoluteSum(int[] nums) {
        int n=nums.length;
		//f[i][0]:以 a[i] 结尾的最大子数组和
		//f[i][1]:以a[i]结尾的最小子数组和
        int[][] f=new int[n+1][2];
        //子数组可以为空
        int ans=0;
        for(int i=0;i<n;i++){
            f[i+1][0]=Math.max(f[i][0],0)+nums[i];
            f[i+1][1]=Math.min(f[i][1],0)+nums[i];
            ans=Math.max(ans,Math.max(f[i+1][0],-f[i+1][1]));
        }
        return ans;
    }
}
```
还可以换种思路，f\[i]\[0]:以 a\[i] 结尾最大正数和。
f\[i]\[1]:以 a\[i] 结尾最小负数和。
那么只要维护f\[i]\[0]始终>=0,f\[i]\[1]始终<=0即可
```java
class Solution { 
	public int maxAbsoluteSum(int[] nums) { 
		int n=nums.length; 
		int[][] f=new int[n+1][2]; 
		int ans=0;
		for(int i=0;i<n;i++){ 
			if(f[i][0]+nums[i]<=0){ 
				f[i+1][0]=0; 
				f[i+1][1]=f[i][1]+nums[i]; 
			} else if(f[i][1]+nums[i]>=0){ 
				f[i+1][0]=f[i][0]+nums[i]; 
				f[i+1][1]=0; 
			} else{ 
				f[i+1][0]=f[i][0]+nums[i]; 
				f[i+1][1]=f[i][1]+nums[i]; 
			} 
			if(f[i+1][0]>ans) 
				ans=f[i+1][0]; 
			if(-f[i+1][1]>ans) 
				ans=-f[i+1][1]; 
		} 
		return ans; 
	} 
}
```
最后，还可以用前缀和，而且更简单。上一题如果用前缀和，要保证最小子数组和在最大子数组和的左边。而这题，无论在左边还是右边，只要取绝对值都满足题意，因为：
- 如果最大前缀和出现在最小前缀和的**右边**，那么上式算的是最大子数组和。
- 如果最大前缀和出现在最小前缀和的**左边**，那么上式算的是最小子数组和的绝对值。
也不用逐个判断了。因为整个数组的最大前缀和-最小前缀和>=逐个遍历得出的结果。
```java
class Solution {
    public int maxAbsoluteSum(int[] nums) {
        int s = 0, mx = 0, mn = 0;
        for (int x : nums) {
            s += x;
            // mx = Math.max(mx, s);
            // mn = Math.min(mn, s);
            if (s > mx) mx = s;
            else if (s < mn) mn = s; // 效率更高的写法
        }
        return mx - mn;
    }
}
```
