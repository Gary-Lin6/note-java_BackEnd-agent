## 例1：相交链表
#hot100 [相交链表](https://leetcode.cn/problems/intersection-of-two-linked-lists/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260429140559.png|354]]
一般思路：
分别计算A,B链表的长度，然后长的链表往前移，直到两个链表长度相同，再一起往前，第一个相等节点即为所求。

高级思路：
![[Pasted image 20260429140738.png|338]]
A节点走完A再从头走B，B节点走完B再重头走A。
A节点走到相交节点的步数：a+（b-c)
B节点走到相交节点的步数：b+（c-c)
刚好相等，也就是说他们两一直往前走，总会在相交节点处相遇。
而且可以证明他们第一次相遇时就是公共节点。
假设他们第一次相遇的节点不是相交节点。
1. 那么第一次相遇不可能在遍历自己链表之后，因为在此之前肯定与相交节点相遇了。
2. 那么只能在还没遍历完自己链表时相遇。因为他们走的步数相同，所以往前相同步数到相交节点也一定相遇。因此他们第一次相遇时的节点一定是相交节点
```java
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode A = headA, B = headB;
        while (A != B) {
            A = A != null ? A.next : headB;
            B = B != null ? B.next : headA;
        }
        return A;
    }
}
```
## 例2.回文链表
#hot100 [回文链表](https://leetcode.cn/problems/palindrome-linked-list/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260429142043.png|441]]
一般思路：
将原链表反转得一个新链表（不过注意要克隆一遍原链表，因为不克隆的化，反转操作已经将原链表结构改变了）然后将反转链表与原链表逐个比较。

高级思路：
反转整个链表不仅需要额外的空间，而且比较次数也多了一半。
那么可以只反转后半部分的链表，然后将后半部分反转链表与前半部分链表比较即可
```java
class Solution {
    public boolean isPalindrome(ListNode head) {
    //找到中间节点。
        ListNode slow=head;
        ListNode fast=head;
        while(fast!=null&&fast.next!=null){
            fast=fast.next.next;
            slow=slow.next;
        }
        ListNode reverse=reverse(slow);
        //注意是reverse！=null，不能head！=null，因为没断开中间节点，head其实还连着中间节点
        //例 1-2-3-4-5-6
        //反转后：1-2-3-4(和下面4是同一个)
        //       6-5-4
        while(reverse!=null){
            if(head.val!=reverse.val)
                return false;
            head=head.next;
            reverse=reverse.next;
        }
        return true;
    }
    private ListNode reverse(ListNode head){
        ListNode reverse=null;
        while(head!=null){
            ListNode next=head.next;
            head.next=reverse;
            reverse=head;
            head=next;
        }
        return reverse;
    }
}
```
## 例3：环形链表
#hot100 [环形链表](https://leetcode.cn/problems/linked-list-cycle-ii/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260429143110.png|373]]
哈希表思路：
用一个哈希表记录遍历过的节点，第一个重复节点即为环的头节点。

Floyd判圈算法：
![[Pasted image 20260429143709.png|350]]
结论：快慢指针相遇时，慢指针再走a步，就能到达入环点：
证明：
	假设头节点到入环口：a
	慢指针走了：b
	环长：c
	入环口到此时相遇点：d
等价于证明：d+a=kc
快指针走了：2b
假设:满指针走了$k_1$圈，快指针比满指针多走$k_2$圈
1：$(b-a)-d=k_1c$
2：$(2b-a)-(b-a)=k_2c$ 
由2得：$b=k_2c$
代入得：$k_2c-a-d=k_1c$
即：$a+d=(k_2-k_1)c$
得证。

利用：虽然不知道a是多少，但可以重新在头节点开始一个指针，与满指针逐步向后移动，相遇时即为入换点
```java
class Solution {
    public ListNode detectCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (fast == slow) { // 相遇
                while (slow != head) { // 再走 a 步
                    slow = slow.next;
                    head = head.next;
                }
                return slow;
            }
        }
        return null;
    }
}
```
## 例4：删除链表倒数第N个节点
#hot100  [删除链表倒数第N个节点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260429145325.png|388]]
一般思路：先求链表长度l，改成删除第l-n个节点
高级思路：学习例3找入环点时，重头开一个指针的思路。开一个快指针，先向后走n步，然后快慢指针再一起走，快指针到结尾时，满指针就是倒数第n个节点，那要删除它，就需要前一个节点，再弄个前驱节点跟着变化即可。(一点小改进：再弄一个dummy节点在头节点前面，这样就统一了头节点和其他节点的操作。（头节点找不到前驱节点）)
```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
       ListNode fast=head;
       ListNode dummy=new ListNode(0);
       dummy.next=head;
       ListNode slow=dummy;
       for(int i=0;i<n;i++)
            fast=fast.next;
        while(fast!=null){
            fast=fast.next;
            slow=slow.next;
        }
        slow.next=slow.next.next;
        return dummy.next;
    }
}
```

## 例5：随机链表的复制
#hot100 [随机链表的复制](https://leetcode.cn/problems/copy-list-with-random-pointer/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260430145335.png|464]]
思路：这题难就难在如果你先复制一条链表，再给random赋值，你会发现定为到新链表的random要重头遍历一遍。
解决办法，先不重新复制一条链表，而是将新节点链在老节点后面，利用老节点已赋值完的random来给新节点的random赋值
```java
class Solution {
    public Node copyRandomList(Node head) {
        Node cur=head;
        while(cur!=null){
            Node copynode=new Node(cur.val);
            copynode.next=cur.next;
            cur.next=copynode;
            cur=copynode.next;
        }
        cur=head;
        while(cur!=null){
            Node copynode=cur.next;
            copynode.random=cur.random==null?null:cur.random.next;
            cur=copynode.next;
        }
        Node dummy=new Node(0);
        Node n=dummy;
        cur=head;
        while(cur!=null){
            n.next=cur.next;
            cur.next=cur.next.next;
            cur=cur.next;
            n=n.next;
        }
        return dummy.next;
    }
}
```
## 例6：LRU缓存
#hot100 [LRU缓存](https://leetcode.cn/problems/lru-cache/solutions/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260430150442.png|401]]
思路：缓存，应该是一个Map，而要实现LRU效果，应该能想到用链表，那么java给我们提供了一个类：LinkedHashMap，他的遍历顺序与存入顺序相同，因此，遍历的第一个节点就是最老的节点。那么我们只用实现取值时，把值移除再插入，即可实现更新操作。插入值时只用判断是不是已有，有的话更新，没有的话判断容量，没满插入，满了删掉第一个再插入
```java
class LRUCache {
    private int capacity;
    private LinkedHashMap<Integer,Integer> lhp;
    public LRUCache(int capacity) {
        this.capacity=capacity;
        this.lhp=new LinkedHashMap<>(capacity);
    }
    public int get(int key) {
    //利用remove结果来判断存不存在
        Integer value=lhp.remove(key);
        if(value==null)
            return -1;
        lhp.put(key,value);
        return value;
    }
    public void put(int key, int value) {
       Integer result=lhp.remove(key);
       if(result!=null){
            lhp.put(key,value);
            return;
       }
        if(lhp.size()==capacity){
            int eldestKey=lhp.keySet().iterator().next();
            lhp.remove(eldestKey);
        }
        lhp.put(key,value);
    }
}
```

class Solution {
    private int ans=0;
    public int pathSum(TreeNode root, int targetSum) {
       if(root==null)
            return 0;
        dfs(root,targetSum);

        pathSum(root.left,targetSum);

        dfs(node.left,targetSum);
        dfs(node.right,targetSum);
        //什么时候需要回溯？
        //其实无论引用类型还是基本类型，都会回溯
        //只不过基本类型传的是值，所以对之前的值没有影响。
        //而引用类型传的是地址，所以要手动将其还原。不然影响之前节点的递归。
    }

class Solution {

#### 例3：路径总和3
#hot100 [路径总和3](https://leetcode.cn/problems/path-sum-iii/description/)
![[Pasted image 20260507132329.png|470]]
这题和路径总和2的区别在于，路径不需要从根节点开始：因此pathSum还得递归。且不需要在叶子节点结束，因此判断是否添加答案，不用判断当前节点是不是叶子节点
```java
class Solution {
    private int ans=0;
    public int pathSum(TreeNode root, int targetSum) {
       if(root==null)
            return 0;
        dfs(root,targetSum);
		//不一定从根节点开始出发
        pathSum(root.left,targetSum);
        pathSum(root.right,targetSum);
        return ans;
    }
    private void dfs(TreeNode node,long targetSum){
        if(node==null)
            return;
        targetSum-=node.val;
        //不用判断是不是叶子节点
        if(targetSum==0)
            ans++;
        dfs(node.left,targetSum);
        dfs(node.right,targetSum);
    }
}
```
但这题其实与路径总和2还有区别，就是只用判断路径个数，而不是完整路径。因此我们可以把某段路径（node_n->...->node_m）的和拆成（root->...->node_m)的和-（root->...->node_n）的和，就不就和数组的前缀和一样了吗？[[技巧#二.前缀和]]，那么我们枚举终点，维护root到终点前的哈希表即可。
```java
class Solution {
    Map<Long,Integer> map=new HashMap<>();
    private int ans=0;
    public int pathSum(TreeNode root, int targetSum) {
	    //注意前面要多放个<0,1>，否则如果根节点到某个节点刚好为0时，会因为哈希表里没有0，而导致少算
        map.put(0l,1);
        dfs(root,0,targetSum);
        //这里不用递归左右节点，因为我们枚举的就是终点。
        return ans;
    }
    private void dfs(TreeNode node,long s,int targetSum){
        if(node==null)
            return;
        s+=node.val;
        ans+=map.getOrDefault(s-targetSum,0);
        map.merge(s,1,Integer::sum);
        dfs(node.left,s,targetSum);
        dfs(node.right,s,targetSum);
        //回溯
        map.merge(s,-1,Integer::sum);
    }
}
```

### 1.2非自顶向下
可以从任意节点到另一个任意节点
即可以是“折”线，也可以是从上到下。

**模板**
思路：折线可以拆分成，节点，左自顶向下，右自顶向下。所以这种题就转换成了自顶向下问题，只不过答案改变时要把左右和节点结合起来判断。
```java
class Solution {
    private int ans=0;
    public int diameterOfBinaryTree(TreeNode root) {
        dfs(root);
        return ans;
    }
    //dfs不再单纯为了递归，它也可以根据要求返回值，比如最大深度等
    private int dfs(TreeNode node){
        if(node==null)
            return 0;
        //分别求左，右
        int left=dfs(node.left);
        int right=dfs(node.right);
        //更新答案
        ans=Math.max(ans,left+right);
        //返回值要根据dfs含义
        return Math.max(left,right)+1;
    }
}
```

#### 例3：最长同值路径
#hot100 [最长同值路径](https://leetcode.cn/problems/longest-univalue-path/description/)
![[Pasted image 20260507140046.png|390]]
某节点最长同值路径可以拆分成，与左节点值相同的自顶向下最长路径，与右节点值相同自顶向下最长路径，该节点，接着判断左右节点与该节点值是否相同，相同则可以合并，不相同说明左/右最长同值路径为0。接着更新ans即可。

class Solution {

    private int dfs(TreeNode node){
        if(node==null)
            return 0;

        int right=dfs(node.right);
        if(node.left!=null&&node.left.val==node.val)
            left++;
        else left=0;
        if(node.right!=null&&node.right.val==node.val)
            right++;
        else right=0;
        ans=Math.max(ans,left+right);
        return Math.max(left,right);
    }

## 2.最近公共祖先
一般是问两个节点的最近公共祖先是谁。
可以根据题目意思，判断这两个节点与当前节点的关系，如果都在左边，则说明最近公共祖先在当前节点的左边，递归，右边同理。如果该节点与某个要找节点相同，或者要找节点在该节点的左右两边，说明该节点就是最近公共祖先

### 例1：二叉树的最近公共祖先
#hot100  [二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260507145013.png|361]]
```java
class Solution {
	//这里的返回值有两个含义，一是最近公共祖先，二是p/q，
	//当然p，q也可能为最近公共祖先
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
	    //找p，q位置，没找到返回null，找到返回p/q。这里把两种情况合并了
        if(root==null||root==p||root==q)
            return root;
        //l，r既可以表示找没找到p，q，又可以表示最近公共祖先
        //如果两个不为空，l，r代表的是p，q
        //如果有一个为空，另一个代表的是最近公共祖先。
        TreeNode l=lowestCommonAncestor(root.left,p,q);
        TreeNode r=lowestCommonAncestor(root.right,p,q);
        //如果p，q在两边分别找到说明，该节点就是最近公共祖先。
        if(l!=null&&r!=null)
            return root;
        //如果左节点为空，说明pq都在右子树那。直接返回r即可，因为此时r的含义就是最近公共祖先
        //不为空同理。
        return l==null?r:l;
    }
}
```
