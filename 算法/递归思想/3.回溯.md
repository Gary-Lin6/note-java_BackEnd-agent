# 一.子集型回溯
## 1.模板
子集型回溯一般是让你求集合的子集。常用的方法有选或不选，或者枚举选哪个。
```java
//选或不选
class Solution {
    List<List<Integer>> ans=new ArrayList<>();
    public List<List<Integer>> subsets(int[] nums) {
       List<Integer> path=new ArrayList<>();
       dfs(nums,path,0);
       return ans;
    }
    private void dfs(int[] nums,List<Integer> path,int i){
        if(i==nums.length){
            ans.add(new ArrayList(path));//注意这里path是引用类型，如果不新建一个对象的话，最终答案里的path都是同一个。
            return;
        }
        dfs(nums,path,i+1);  //不选第i个
        path.add(nums[i]);
        dfs(nums,path,i+1);  //选第i个
        path.remove(path.size()-1);  
       /* 
注意这里要移除最后一个，也就是刚加上的第i个。因为如果不移除的话，对于第i-1（上一个）个而言，
        ...
     /       \
  不选i-1   选i-1   
   /   \     /   \
不选i   选i  不选i  选i
        ...
他会先递归不选i-1的情况，在这种情况下，会分别递归不选i，和选i的情况，如果path不移除选i的情况，会影响选i-1的情况（path此时已经含了i），所以在归结束前，要把path还原。
这也看出清理最后一个元素的原因：共用一个path，当然你可以每次递归新建一个path，但这也太浪费空间了。
*/
    }
}
```
```java
//枚举选哪个
class Solution {
    List<List<Integer>> ans=new ArrayList<>();
    public List<List<Integer>> subsets(int[] nums) {
       List<Integer> path=new ArrayList<>();
       dfs(nums,path,0);
       return ans;
    }
    //从i到n-1选一个数到path
    private void dfs(int[] nums,List<Integer> path,int i){
       ans.add(new ArrayList(path));//每次递归，path都为0-i-1的一个子集
       for(int j=i;j<nums.length;j++){
            path.add(nums[j]);
            dfs(nums,path,j+1);
            path.remove(path.size()-1);
       }
    }
/*
相当于从答案的视角，第一个数选谁，第二个数选谁...
因此每个path都为一个path.size()的答案。
循环从i—n-1选第path.size()+1个数。
*/
}
```
我个人还是更喜欢选或不选的方法，感觉理解起来更简单。

### 例2：分割回文串
#hot100 [分割回文串](https://leetcode.cn/problems/palindrome-partitioning/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260519135742.png|515]]
划分型回溯，其实可以看作在此处选或不选逗号（划不划分），本质上还是子集型回溯
```java
class Solution {
    List<List<String>> ans=new ArrayList();
    public List<List<String>> partition(String s) {
        dfs(s,new ArrayList(),0,0);
        return ans;
    }
    private void dfs(String s,List<String> path,int start,int end){
        if(end==s.length()){
            //到结尾，如果还能划分，说明该划分可行，添加答案
            if(isPalindromic(s,start,end-1)){
                path.add(s.substring(start,end));
                ans.add(new ArrayList(path));
                path.remove(path.size()-1);
            }
            //如果结尾剩下的字符串不能划分说明该划分不可行，直接返回
            return;
        }
        //能划分才划分，不同于纯子集型回溯，否则如果随意划分，每个划分都要检查。
        if(isPalindromic(s,start,end)){
            path.add(s.substring(start,end+1));
            dfs(s,path,end+1,end+1);
            path.remove(path.size()-1);
        }
        //不划分
        dfs(s,path,start,end+1);
    }
    private boolean isPalindromic(String s,int start,int end){
        if(end<start)
            return false;
        while(start<end){
            if(s.charAt(start++)!=s.charAt(end--))
                return false;
        }
        return true;
    }
}
```
# 二.组合型回溯
## 1.模板
该类问题一般让你求在n个数里选k个的所有情况
本质上是在子集里选个数为k的子集。
那么也就可以用子集型回溯的两种方法来做，只不过在加答案时要判断子集元素个数是否满足要求。也可以在子集元素个数大于要求时剪枝。
```java
//选或不选
```java
class Solution {
    private List<List<Integer>> ans=new ArrayList<>();
    //在1-n里选k个数
    public List<List<Integer>> combine(int n, int k) {
        dfs(n,new ArrayList(),k,1);
        return ans;
    }
    private void dfs(int n,List<Integer> path,int k,int i){
	    //剪枝
        if(path.size()>k)
            return; 
        if(i==n+1){
	        //判断此时path个数是否满足要求
            if(path.size()==k)
                ans.add(new ArrayList(path));
            return;
        }
        //不选
        dfs(n,path,k,i+1);
        //选
        path.add(i);
        dfs(n,path,k,i+1);
        path.remove(path.size()-1);
    }
}
```
```java
//枚举选哪个
//此时用这种方法更容易理解了，前面说，递归前，每个path：元素个数为path.size()的子集，直接判断==k？即可。
```java
class Solution {
    private List<List<Integer>> ans=new ArrayList<>();
    public List<List<Integer>> combine(int n, int k) {
        dfs(n,new ArrayList(),k,1);
        return ans;
    }
    private void dfs(int n,List<Integer> path,int k,int i){
	    //判断子集元素个数
        if(path.size()==k){
            ans.add(new ArrayList(path));
            return;
        }
        //枚举第path.size()+1个元素选哪个
        for(int j=i;j<=n;j++){
            path.add(j);
            dfs(n,path,k,j+1);
            path.remove(path.size()-1);
        }
    }
}
```

### 例2：组合总和
#hot100 [组合总和](https://leetcode.cn/problems/combination-sum/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260519142254.png|496]]
和常规组合不同在于，他可以重复选同一个数。用选或不选的方法来做的话，不选就直接跳过（i+1），选了还能再选（i不变）
```java
class Solution {
    List<List<Integer>> ans=new ArrayList<>();
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        dfs(candidates,new ArrayList(),target,0);
        return ans;
    }
    //选或不选第i个
    private void dfs(int[] candidates,List<Integer> path,int target,int i){
	    //选完了，或者选超了，直接剪枝
        if(i==candidates.length||target<0)
            return;
        //满足要求，加入答案
        if(target==0){
            ans.add(new ArrayList(path));
            return;
        }
        //不选，i+1
        dfs(candidates,path,target,i+1);
        //选
        path.add(candidates[i]);
        target-=candidates[i];
        dfs(candidates,path,target,i);
        path.remove(path.size()-1);//这里target不用回溯，因为它是基本类型，存储在栈中，对递归前没有影响。这也反应了，为什么path要移除最后一个元素：因为他是引用类型
    }
}
```
如果用枚举选哪个的话，同样的选了第j个后，i应该等于j而不是j+1，表示j可以重复选
```java
class Solution {
    List<List<Integer>> ans=new ArrayList<>();
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        dfs(candidates,new ArrayList(),target,0);
        return ans;
    }
    //枚举选第i-n-1个数
    private void dfs(int[] candidates,List<Integer> path,int target,int i){
	    //剪枝
        if(target<0)
            return;
        //加入答案
        if(target==0){
            ans.add(new ArrayList(path));
            return;
        }
        for(int j=i;j<candidates.length;j++){
            path.add(candidates[j]);
            //注意不能单独写：target-=candidates[j]，因为会对循环后面造成影响，除非你“回溯”，即在后面target+=candidates[j],那还不如直接传参呢。
            dfs(candidates,path,target-candidates[j],j);//注意这里i==j，表示可以重复选
            path.remove(path.size()-1);
        }
    }
}
```
### 例3：括号生成
#hot100 [括号生成](https://leetcode.cn/problems/generate-parentheses/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260519144753.png]]
本质上实在2n里选n个位置放左括号，只不过要保证括号要合法：即左括号数一直>=右括号数
```java
class Solution {
    private List<String> ans=new ArrayList<>();
    public List<String> generateParenthesis(int n) {
        dfs(n,new StringBuilder(),0,0);
        return ans;
    }
    private void dfs(int n,StringBuilder sb,int l,int r){
        if(l==n&&r==n){
            ans.add(sb.toString());
            return;
        }
        //剪枝
        if(l<r||l>n||r>n)
            return;
        //放左括号
        dfs(n,sb.append("("),l+1,r);
        sb.deleteCharAt(l+r);  //去掉第l+r，即刚加的左括号，避免影响后面的右括号
        //放右括号
        dfs(n,sb.append(")"),l,r+1);
        sb.deleteCharAt(l+r);  //去掉第l+r，即岗加的右括号，避免影响递归上一个的sb
    }
}
```
如果用枚举下一个左括号的方法，要注意右括号个数不能超过左括号个数，具体可以看[题解](https://leetcode.cn/problems/generate-parentheses/solutions/2071015/hui-su-bu-hui-xie-tao-lu-zai-ci-pythonja-wcdw/?envType=study-plan-v2&envId=top-100-liked)

# 三.排序型回溯
## 1.模板
排列型回溯可以看作每次都从0-n里选一个数,但要注意不能选重了，所以可以用一个辅助数组visit来表示是否选过。
```java
class Solution {
    private List<List<Integer>> ans=new ArrayList<>();
    private boolean[] visit;
    public List<List<Integer>> permute(int[] nums) {
        int n=nums.length;
        this.visit=new boolean[n];
        dfs(nums,new ArrayList(),0);
        return ans;
    }
    //第index个位置从0-n-1里选一个
    private void dfs(int[] nums,List<Integer> path,int index){
		//选完了，直接加入答案
        if(index==nums.length){
            ans.add(new ArrayList(path));
            return;
        }
        for(int i=0;i<nums.length;i++){
			//枚举没选过的数
            if(!visit[i]){
                path.add(nums[i]);
                visit[i]=true;
                dfs(nums,path,index+1);
                visit[i]=false;    //注意path,visit都要回溯，因为会影响到下次循环。
                path.remove(path.size()-1);  
            }
        }
    }
}
```

### 例2：电话号码的字母组合
#hot100 [电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260519151332.png]]
其实算不上全排列。相当于每个数字，从对应字母里选一个字母。
```java
class Solution {
    List<String> ans=new ArrayList<>();
    String[] map=new String[]{"","","abc","def","ghi","jkl","mno","pqrs","tuv","wxyz"};
    public List<String> letterCombinations(String digits) {
        dfs(digits.toCharArray(),new StringBuilder(),0);
        return ans;
    }
    private void dfs(char[] digits,StringBuilder sb,int i){
        if(i==digits.length){
            ans.add(sb.toString());
            return;
        }
        //数字对应能选的字母
        String choose=map[digits[i]-'0'];
        for(char c:choose.toCharArray()){
            dfs(digits,sb.append(c),i+1);  //选第几个
            sb.deleteCharAt(sb.length()-1);  //回溯，避免对后续循环有影响
        }
    }
}
```
### 例3：N皇后
#hot100 [N皇后](https://leetcode.cn/problems/n-queens/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260519151727.png]]
![[Pasted image 20260519151736.png]]
相当于每一行，选一个能放的位置放皇后。
能放：例1全排列的能放指的是不重复，这里的能放，指的是不被前面行放的皇后攻击到。也就是，不在同一列，不在斜线上。
不在同一列比较简单，不在斜线上怎么判断？可以参考[[技巧#3.遍历对角线]]，“/”这样子的对角线行+列为定值，“\”这样子的对角线，列-行为定值。
所以我们逐个判断前面行的皇后能不能攻击到即可
```java
class Solution {
    private List<List<String>> ans=new ArrayList();
    public List<List<String>> solveNQueens(int n) {
       dfs(n,new int[n],0);
       return ans;
    }
    //放第i行的皇后
    //path[i]指第i行放第几列
    private void dfs(int n,int[] path,int i){
		//所有行都放上了，说明该方案可行
        if(i==n){
            List<String> tmp=new ArrayList<>();
            //每一行按答案的表示
            for(int j=0;j<n;j++){
                StringBuilder sb=new StringBuilder();
                for(int k=0;k<path[j];k++)
                    sb.append(".");
                sb.append("Q");
                for(int k=0;k<n-path[j]-1;k++)
                    sb.append(".");
                tmp.add(sb.toString());
            }
            ans.add(tmp);
        }
        //遍历0-n-1列，看能不能放
        for(int j=0;j<n;j++){
            if(isValid(path,i,j)){
                path[i]=j;
                dfs(n,path,i+1);
            }
        }

    }
    private boolean isValid(int[] path,int i,int j){
		//看前i行皇后，会不会攻击到第i行，第j列的皇后
        for(int k=0;k<i;k++){
            if(path[k]==j||path[k]+k==i+j||path[k]-k==j-i)
                return false;
        }
        return true;
    }
}
```
