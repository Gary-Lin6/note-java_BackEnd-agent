# 一.定长滑动窗口
## 1.定长滑窗套路

窗口右端点在 i 时，由于窗口长度为 k，所以窗口左端点为 i−k+1。

我总结成三步：入-更新-出。

入：下标为 i 的元素进入窗口，更新相关统计量。如果窗口左端点 i−k+1<0，则尚未形成第一个窗口，重复第一步。
更新：更新答案。一般是更新最大值/最小值。
出：下标为 i−k+1 的元素离开窗口，更新相关统计量，为下一个循环做准备。
以上三步适用于所有定长滑窗题目。






## 2.例题
### 例1：[定长字串中元音的最大数目](https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length/description/)
![[定长字串中元音的最大数目.png|377]]
```java
class Solution {
    public int maxVowels(String S, int k) {
        char[] s = S.toCharArray();
        int ans = 0;
        int vowel = 0;
        for (int i = 0; i < s.length; i++) { // 枚举窗口右端点 i
            // 1. 右端点进入窗口
            if (s[i] == 'a' || s[i] == 'e' || s[i] == 'i' || s[i] == 'o' || s[i] == 'u') {
                vowel++;
            }

            int left = i - k + 1; // 窗口左端点
            if (left < 0) { // 窗口大小不足 k，尚未形成第一个窗口
                continue;
            }

            // 2. 更新答案
            ans = Math.max(ans, vowel);

            // 3. 左端点离开窗口，为下一个循环做准备
            char out = s[left];
            if (out == 'a' || out == 'e' || out == 'i' || out == 'o' || out == 'u') {
                vowel--;
            }
        }
        return ans;
    }
}
```

### 例2：找到字符串中所有字母异位词
[找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/description/?envType=study-plan-v2&envId=top-100-liked)
#hot100 
![[找到字符串中所有字母异为词.png|432]]
思路：相当于在s中找定长（p的长度）的滑动窗口，使得滑动窗口内的字符串时p的异位词。接下来的问题就是怎么判断异位词了。可以用一个数组记录p各字符出现次数，一个数组记录s各字符出现次数，然后用Arrays.equals来比较数组是否相等，或者自己写一个函数判断即可。
```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> ans=new ArrayList<>();
        int n=s.length();
        int k=p.length();
        int[] pcnt=new int[26];
        int[] scnt=new int[26];
        for(int i=0;i<k;i++){
            pcnt[p.charAt(i)-'a']++;
        }
        for(int i=0;i<n;i++){
            scnt[s.charAt(i)-'a']++;
            int left=i-k+1;
            if(left<0)
                continue;
            if(Arrays.equals(scnt,pcnt))
                ans.add(left);
            scnt[s.charAt(left)-'a']--;
            left++;
        }
        return ans;
    }
}
```




# 二.不定长滑动窗口

思想：用同向双指针，left,right,枚举右指针right,对每一个right,移动left，使得条件仍成立。更新此时窗口最大/最小/个数


## 1.越短越合法/求最长/最大

### 例1.无重复字符的最长字串
[无重复字符的最长字串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/)
#hot100
![[无重复字符的最长字串.png|371]]

用一个Set/int[]/boolean[] 来存储窗口内元素存在情况，枚举右指针，移动做指针，使得窗口内元素不重复，更新答案最大值。
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> set=new HashSet<>();
        int left=0;
        int right=0;
        int ans=0;
        int n=s.length();
        while(right<n){
            while(set.contains(s.charAt(right))){
                set.remove(s.charAt(left));
                left++;
            }
            set.add(s.charAt(right));
            ans=Math.max(ans,right-left+1);
            right++;
        }
        return ans;
    }
}
```

## 2.越长越合法/求最短/最小

和越短越合法类似，但是ans初始值和ans的更新不同

### 例1：长度最小子数组
[长度最小子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/description/)
![[长度最小子数组.png|348]]
```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int left=0;
        int right=0;
        int n=nums.length;
        int ans=n+1;
        int sum=0;
        while(right<n){
            sum+=nums[right];
            while(sum-nums[left]>=target){
                sum-=nums[left];
                left++;
            }
            if(sum>=target)
                ans=Math.min(ans,right-left+1);
            right++;
        }
        return ans==n+1?0:ans;
    }
}
```

### 例2：最小覆盖字串
#hot100 [最小覆盖字串](https://leetcode.cn/problems/minimum-window-substring/description/)
![[最小覆盖字串.png|383]]
我的思路：用tcnt数组储存字符t中各字符的数量，scnt数组储存窗口中各字符数量，窗口内需满足scnt覆盖tcnt（即窗口各个字符数量都要>=t对应的字符数量）。接着滑动窗口找最小即可
```java
class Solution {
    private final static int SIZE=128;
    public String minWindow(String s, String t) {
        int[] scnt=new int[SIZE];
        int[] tcnt=new int[SIZE];
        int m=s.length();
        int n=t.length();
		if(m<n)
			return "";
        for(int i=0;i<n;i++)
            tcnt[t.charAt(i)]++;
        int left=0;
        int right=0;
        int ans=m+1;
        int ans_right=m+1;
        int ans_left=-1;
        while(right<m){
            scnt[s.charAt(right)]++;
            while(isCover(scnt,tcnt)){
                if(ans>right-left+1){
                    ans=right-left+1;
                    ans_left=left;
                    ans_right=right;
                }
                scnt[s.charAt(left)]--;
                left++;
            }
            right++;
        }
        return ans==m+1?"":s.substring(ans_left,ans_right+1);
    }
    private boolean isCover(int[] scnt,int[] tcnt){
        for(int i=0;i<SIZE;i++){
            if(scnt[i]<tcnt[i])
                return false;
        }
        return true;
    }
}
```
但这样每次判断是否覆盖要花费O（SIZE）的时间。能否优化成O（1）？
思路：
用diff[i]存储s[i]-t[i];
用cnt来统计窗口中已覆盖t对应字符的字符数。
当cnt== t不同字符字符总数（kinds)时,窗口满足条件。
如何维护cnt:
右指针右移，新增s[i]，diff[s[i]]++，若此时diff[s[i]]== 0，说明此时覆盖了个新字符，cnt++;
左指针右移，去掉s[i]，diff[s[i]]--，若此时diff[s[i]]<0，说明不再覆盖s[i]，cnt--;
```java
class Solution {
    private final static int SIZE=128;
    public String minWindow(String s, String t) {
        int m=s.length();
        int n=t.length();
        if(m<n)
            return "";
        int[] diff=new int[SIZE];
        int kinds=0;
        for(int i=0;i<n;i++){
            if(diff[t.charAt(i)]==0)
                kinds++;
            diff[t.charAt(i)]--;
        }
        int cnt=0;
        int left=0;
        int right=0;
        int ans=m+1;
        int ans_right=m+1;
        int ans_left=-1;
        while(right<m){
            diff[s.charAt(right)]++;
            if(diff[s.charAt(right)]==0)
                cnt++;
            while(cnt==kinds){
                if(ans>right-left+1){
                    ans=right-left+1;
                    ans_left=left;
                    ans_right=right;
                }
                if(diff[s.charAt(left)]==0)
                    cnt--;
                diff[s.charAt(left)]--;
                left++;
            }
            right++;
        }
        return ans==m+1?"":s.substring(ans_left,ans_right+1);
    }
}
```

## 3.求子数组个数
### 3.1越短越合法/最长
一般要写 ans += right - left + 1。

内层循环结束后，[left,right] 这个子数组是满足题目要求的。由于子数组越短，越能满足题目要求，所以除了 [left,right]，还有 [left+1,right],[left+2,right],…,[right,right] 都是满足要求的。也就是说，当右端点固定在 right 时，左端点在 left,left+1,left+2,…,right 的所有子数组都是满足要求的，这一共有 right−left+1 个。

#### 例1：乘积小于k的子数组
```java
class Solution {
    public int numSubarrayProductLessThanK(int[] nums, int k) {
		if(k<=1)
			return 0;//不特判的话mul肯定始终大于k，导致while(mul>=k)无法退出
        int n=nums.length;
        int left=0;
        int right=0;
        int mul=1;
        int ans=0;
        while(right<n){
            mul*=nums[right];
            while(mul>=k){
                mul/=nums[left];
                left++;
            }
            ans+=right-left+1 //理由见上方解释
            right++;
        }
        return ans;
    }
}
```
### 3.2越长越合法/最短

一般要写 ans += left。

内层循环结束后，[left,right] 这个子数组是不满足题目要求的，但在退出循环之前的最后一轮循环，[left−1,right] 是满足题目要求的。由于子数组越长，越能满足题目要求，所以除了 [left−1,right]，还有 [left−2,right],[left−3,right],…,[0,right] 都是满足要求的。也就是说，当右端点固定在 right 时，左端点在 0,1,2,…,left−1 的所有子数组都是满足要求的，这一共有 left 个。

我们关注的是 left−1 的合法性，而不是 left。

#### 例1：包含所有三种字符的子字符串数目
[包含所有三种字符的子字符串数目](https://leetcode.cn/problems/number-of-substrings-containing-all-three-characters/description/)

```java
class Solution {
    public int numberOfSubstrings(String s) {

                cnt[s.charAt(left)-'a']--;

                    cover--;
                left++;
            }
            ans+=left;//为什么正确，
		            //如果是退出了上轮循环来到这，原因见上
		            //那如果这一轮right没进循环呢？
		            //1.还没有进过cover==3的循环：
		            //left==0,没影响。
		            //2.进过cover==3的循环：
		            //即使这一轮没有进循环，但之前进过循环，且在left++后刚好退出了循环，说明[0~left-1，cur_right]也是满足条件的，因为[0...left-1,right]包含于[0~left-1，cur_right]
            right++;
        }
        return ans;
    }
}
```

### 3.3恰好型滑动窗口
例如，要计算有多少个元素和恰好等于 k 的子数组，可以把问题变成：

计算有多少个元素和 ≥k 的子数组。
计算有多少个元素和 >k，也就是 ≥k+1 的子数组。
答案就是元素和 ≥k 的子数组个数，减去元素和 ≥k+1 的子数组个数。这里把 > 转换成 ≥，从而可以把滑窗逻辑封装成一个函数 solve，然后用 solve(k)−solve(k+1) 计算，无需编写两份滑窗代码。

总结：「恰好」可以拆分成两个「至少」，也就是两个「越长越合法」的滑窗问题。

注：也可以把问题变成 ≤k 减去 ≤k−1，即两个「至多」。可根据题目选择合适的变形方式。

注：也可以把两个滑动窗口合并起来，维护同一个右端点 right 和两个左端点 left1​和left2，我把这种写法叫做三指针滑动窗口。

#### 例1：和相同的二元子数组
[和相同的二元子数组](https://leetcode.cn/problems/binary-subarrays-with-sum/description/)

```java
//solve 方法解决
class Solution {
    public int numSubarraysWithSum(int[] nums, int goal) {
        return solve(nums,goal)-solve(nums,goal+1);
    }
    private int solve(int[] nums,int goal){
        int n=nums.length;
        int left=0;
        int right=0;
        int ans=0;
        int sum=0;
        while(right<n){
            sum+=nums[right];
            while(left<=right&&sum>=goal){//这里要加left<=right原因：goal可能为0，导致循环无法退出，从而导致left下标越界。
                sum-=nums[left];
                left++;
            }
            ans+=left;
            right++;
        }
        return ans;
    }
}
```

```java
//两个左指针
class Solution {
    public int numSubarraysWithSum(int[] nums, int goal) {
        int n=nums.length;
        int left1=0;
        int left2=0;
        int right=0;
        int ans1=0;
        int ans2=0;
        int sum1=0;
        int sum2=0;
        while(right<n){
            sum1+=nums[right];
            sum2+=nums[right];
            while(left1<=right&&sum1>=goal){
                sum1-=nums[left1];
                left1++;
            }
            ans1+=left1;
            while(left2<=right&&sum2>=goal+1){
                sum2-=nums[left2];
                left2++;
            }
            ans2+=left2;
            right++;
        }
        return ans1-ans2;
    }
}
```
