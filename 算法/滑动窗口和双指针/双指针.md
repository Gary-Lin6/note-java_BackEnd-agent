### 题型2：回文串
#### 例1：字典序最小回文串
[字典序最小回文串](https://leetcode.cn/problems/lexicographically-smallest-palindrome/description/)
![[Pasted image 20260417171614.png|300]]
```java
class Solution {
    public String makeSmallestPalindrome(String s) {
        char[] c=s.toCharArray();
        int n=c.length;
        int left=0;
        int right=n-1;
        while(left<right){
            if(c[left]<c[right])
                c[right]=c[left];
            else if(c[left]>c[right])
                c[left]=c[right];
            left++;
            right--;
        }
        return new String(c);
    }
}
```

#### 拓1：三数之和
#hot100 [三数之和](https://leetcode.cn/problems/3sum/description/)
![[Pasted image 20260417174308.png|360]]
思路：
根据例1启发，对于一个有序数组，求两数之和只用O(n)的时间，那对于求三数之和，只用将该数组排序，然后枚举第一个数(i)，那三数之和就转换成两数之和（nums(从i+1到n),target(target-nums[i]))。
需要注意的是，答案要求三元组不重复，那么枚举i时nums[i]！=nums[i-1]，左指针向右移过程中，nums[j]!=nums[j-1]即可。

时间复杂度分析：
将该数组排序O(nlogn)，
枚举第一个数O(n)，两数之和O(n)，
所以总时间复杂度$O(n^2)$
```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
       Arrays.sort(nums);
       List<List<Integer>> ans=new ArrayList<>();
       int n=nums.length;
        for(int i=0;i<n-2;i++){
            if(i!=0&&nums[i]==nums[i-1])
                continue;
            int j=i+1;
            int k=n-1;
            int target=-nums[i];
            while(j<k){
                if(j!=i+1&&nums[j]==nums[j-1]){
                    j++;
                    continue;
                }
                if(nums[j]+nums[k]==target){
                    List<Integer> as=new ArrayList<>();
                    Collections.addAll(as,nums[i],nums[j],nums[k]);
                    ans.add(as);
                    j++;
                    k--;
                }
                else if(nums[j]+nums[k]<target){
                    j++;
                }
                else
                    k--;
            }
       }
       return ans;
    }
}
```

### 题型4：其他
#### 例1：盛最多水的容器
#hot100 [盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/description/)
![[Pasted image 20260417181728.png|340]]
思路：
每次尽可能选最大的容器。
一开始初始化两个指针left=0,right=n-1
假设最大的容器是left~right,想要找到更大容积的容器，只能将矮的柱子向内移动。因为移动高的柱子，一定比现在的情况更小
原因：
1.假设，里面有比现在矮的更高的柱子，但因为接水高度，由矮柱子决定，那么接水高度不变，但宽度变小，总容积变小
2.假设，里面有比现在矮的更矮的柱子，那么接水高度变低，且宽度变小，所以总容积减小，
由此判断，如果移动高柱子，一定不会得到更大的容积。

所以通过移动矮柱子，遍历尽可能大的容器，而最大容器一定在尽可能大的容器中
所以通过比较每次尽可能大容器与ans的大小，得到最大的尽可能大容器

为什么用双指针：只用根据左指针和右指针，就能判断区间是否满足条件。
```java
class Solution {
    public int maxArea(int[] height) {
        int n=height.length;
        int left=0;
        int right=n-1;
        int ans=0;
        while(left<right){
            ans=Math.max(Math.min(height[left],height[right])*(right-left),ans);
            if(height[left]<=height[right])
                left++;
            else
                right--;
        }
        return ans;
    }
}
```

#### 例2：接雨水
#hot100 [接雨水](https://leetcode.cn/problems/trapping-rain-water/description/
![[Pasted image 20260417181814.png|419]]
思路：
竖着看第i格能装的雨水量=min(i左边最高的柱子，i右边最高的柱子)-height[i]
很常见思路：
那么构造两个数组：left,right，left[i]记录i左边最高，right[i]记录i右边最高。
从左到右遍历一次，得到left,从右到左遍历一次得到right
然后遍历数组ans+=min(left[i],right[i])-height[i];
时间复杂度O(n)，空间复杂度O(n).

双指针思路
那么可以优化空间复杂度为O(1)吗？
用双指针，left=0,right=n-1。
用premax记录left及left左边的最大值。用postmax记录right及right右边的最大值。
当premax< postmax时，left左边最大一定比left右边最大小
原因：
1.假设left到right之间还有
因此min(left[i],right[i])== premax,可以直接计入答案，left++;
相反，则right右边最大一定比right左边最大小，因此min(left[i],right[i])== postmax,直接得right格可接雨水，right--;

```java
class Solution {
    public int trap(int[] height) {
        int n=height.length;
        int left=0;
        int right=n-1;
        int premax=0;
        int postmax=0;
        int ans=0;
        while(left<right){
            premax=Math.max(premax,height[left]);
            postmax=Math.max(postmax,height[right]);
            if(premax<postmax){
                ans+=premax-height[left];
                left++;
            }
            else{
                ans+=postmax-height[right];
                right--;
            }
        }
        return ans;
    }
}
```

## 2.同向双指针

滑动窗口其实就是同向双指针。
右指针不断右移，根据题意移动左指针，从而找到窗口最大/最小/个数。
和滑动窗口区别在，右指针不一定从0开始。

### 例1：有效三角形个数
[有效三角形个数](https://leetcode.cn/problems/valid-triangle-number/description/)
![[Pasted image 20260418145833.png|374]]
思路：
能构成三角形的三条边(a<b<c)等价于c-b>a；
先对数组排列
枚举最小边。用同向双指针left表示b，right表示c。若c-b>=a,说明b不够大，left++。
反之说明说明left~right-1都能构成三角形，right++。
```java
class Solution {
    public int triangleNumber(int[] nums) {
        Arrays.sort(nums);
        int n=nums.length;
        int ans=0;
        for(int i=0;i<n-2;i++){
            int a=nums[i];
            if(a==0)//三角形边长>0.同时为下方while循环省了j<k
                continue;
            int j=i+1;
            for(int k=i+2;k<n;k++){
                while(nums[k]-nums[j]>=a)//因为a>0,若j==k时，nums[k]-nums[j]==0,一定<a，k++；
                    j++;
                ans+=k-j;
            }
        }
        return ans;
    }
}
```
### 例2：删除最短子数组使剩余数组有序
[删除最短子数组使剩余数组有序](https://leetcode.cn/problems/shortest-subarray-to-be-removed-to-make-array-sorted/description/)
![[Pasted image 20260418150837.png|427]]
思路：
删除一个子数组，会使原数组分为前缀，后缀两部分（前后缀可以为空）。
要使得剩下元素是非递减的，说明前后缀分别非递减，且前缀最大<=后缀最小。

可以先固定前缀或后缀的范围。
1.比如先固定后缀范围。为right~n-1;
2.接着枚举前缀。对于每个left，都要有arr[left-1]<=arr[left]，
3.接着找满足此时left的right：arr[left]<=arr[right]。
4.更新ans=Math.min(ans,right-left-1)。
注意：
因为已经保证了前，后缀是非递减的。所以枚举下一个left时，right不用重头开始枚举，
因为arr[right-1]<=arr[left]<=arr[right]，且arr[left]<=arr[left+1],所以在right之前的一定小于arr[left+1]。只用接着循环找下一个大于arr[left+1]的right即可。
这使得我们可以用同向双指针来找要删除的子数组。

```java
class Solution {
    public int findLengthOfShortestSubarray(int[] arr) {
        int n=arr.length;
        int right=n-1;
        //先找后缀范围
        while(right>0&&arr[right-1]<=arr[right]){
            right--;
        }
        //特殊情况：原数组已经非递减
        if(right==0)
            return 0;
        int left=0;
        //初始化ans,前缀为空
        int ans=right;
        //枚举前缀
        while(left==0||arr[left-1]<=arr[left]){
	        //找对于每个left，成立的right
            while(right<n&&arr[right]<arr[left])
                right++;
            ans=Math.min(ans,right-left-1);
            left++;
        }
        return ans;
    }
}
```

## 3.背向双指针

#### 例1：找到k个最接近元素
[找到k个最接近元素](https://leetcode.cn/problems/find-k-closest-elements/description/)
![[Pasted image 20260417171913.png|299]]
```java
class Solution {
    public List<Integer> findClosestElements(int[] arr, int k, int x) {
        List<Integer> ans=new ArrayList<>();
        int n=arr.length;
        if(arr[0]-x>=0){
            for(int i=0;i<k;i++)
                ans.add(arr[i]);
            return ans;
            }
        else if(arr[n-1]-x<=0){
            for(int i=n-k;i<=n-1;i++)
               ans.add(arr[i]);
            return ans;
        }
        int right=findlowerbound(arr,x);//找到第一个>=x，的位置
        int left=right-1;
        //背向双指针
        while(k>0){
            if(left<0)
                right++;
            else if(right>=n)
                left--;
            else{
                if((x-arr[left])<=(arr[right]-x)){
                    left--;
                }
                else if((x-arr[left])>(arr[right]-x)){
                    right++;
                }
            }
            k--;      
        }
        for(int i=left+1;i<right;i++)
            ans.add(arr[i]);
        return ans;
    }
    //二分查找
    private int findlowerbound(int[] arr,int k){
        int left=0;
        int right=arr.length-1;
        while(left<right){
            int mid=(left+right)/2;
            if(arr[mid]<k)
                left=mid+1;
            else
                right=mid;
        }
        return left;
    }
}
```
### 例2：好子数组的最大分数
[好子数组的最大分数](https://leetcode.cn/problems/maximum-score-of-a-good-subarray/description/)
![[Pasted image 20260418155708.png|365]]
#### 思路：
类似盛最多水的容器，只不过题目有要求i<=k<=j，那么可以用背向双指针。每次移动一个指针，使得好数组的最大分数尽可能变大：
下一个子数组要么是[left-1,right],要么是[left,right+1],边界情况再讨论。那么如过nums[left-1]>=nums[right+1]，我们移动左指针，并更新区间内最小值。
**原因**：
假设cur_min为区间最小值，
如果cur_min>nums[left-1]>nums[right+1],那么移动左指针会比移动右指针的下一个好数组大。
如果nums[left-1]>cur_min>nums[right+1]，显然移动左指针好数组更大，
nums[left-1]>nums[right+1]>cur_min，同理。
反之，移动右指针。在遍历左右指针过程中一定能遍历到最大好子数组。更新ans即可。
```java
class Solution {
    public int maximumScore(int[] nums, int k) {
        int n=nums.length;
        int left=k;
        int right=k;
        int ans=0;
        int cur_min=nums[k];
        while(true){
            ans=Math.max(ans,cur_min*(right-left+1));
            //左右指针不能再移动了
            if(left==0&&right==n-1)
                break;
            //左指针不能移
            if(left==0){
                right++;
                cur_min=Math.min(cur_min,nums[right]);
            }
            //右指针不能移
            else if(right==n-1){
                left--;
                cur_min=Math.min(cur_min,nums[left]);
            }
            else if(nums[left-1]>=nums[right+1]){
                left--;
                cur_min=Math.min(cur_min,nums[left]);
            }
            else if(nums[right+1]>nums[left-1]){
                right++;
                cur_min=Math.min(cur_min,nums[right]);
            }
        }
        return ans;
    }

}
```
## 4.原地修改
为什么双指针可以用来原地修改？
答:双指针能把数组划分成三个部分

例如在移动0中，
第一部分（0~left)：非0
第二部分（left~right):0
第三部分（right~n):待处理

那么逐渐移动双指针，直到待处理部分为空，就完成了题目。

待处理可能在1，2，3部分，要灵活使用相向，同向，背向划分区间。

### 例1：移动0
#hot100 [移动0](https://leetcode.cn/problems/move-zeroes/description/)
![[Pasted image 20260418162213.png|383]]
```java
//思路见上
class Solution {
    public void moveZeroes(int[] nums) {
        int n=nums.length;
        int left=0;
        int right=0;
        while(right<n){
            if(nums[right]!=0){
                swap(nums,left,right);
                left++;
            }
            right++;
        }
    }
    private void swap(int[] nums,int i,int j){
        int temp=nums[i];
        nums[i]=nums[j];
        nums[j]=temp;
    }
}
```

### 例2:颜色分类
#hot100 [颜色分类](https://leetcode.cn/problems/sort-colors/description/)
![[Pasted image 20260418163636.png|334]]
**思路**
这题我用了三指针。别的方法见题解吧。
类似上一题移动0，用了双指针来区分0和非0。那么就可以用三指针来区分0，1，2。
第一部分（0~left)：0
第二部分（left~scan):1
第三部分（scan~right):待处理
第四部分（right~n）:2

```java
class Solution {
    public void sortColors(int[] nums) {
        int n=nums.length;
        int left=0;
        int scan=0;
        int right=n-1;
        while(scan<=right){
            if(scan<left||nums[scan]==1)
                scan++;
            else if(nums[scan]==0){
                swap(nums,left,scan);
                left++;
            }
            else if(nums[scan]==2){
                swap(nums,right,scan);
                right--;
            }
        }
    }
    private void swap(int[] nums,int i,int j){
        int tmp=nums[i];
        nums[i]=nums[j];
        nums[j]=tmp;
    }
}
```
由此类推，区分0，1，2，3...都可以解决了。
