## 1.二分模板
注：nums为非递减数组。
findLowerBound:找到第一个>=target的下标
记一个就好。个人喜欢闭区间和开区间
特殊情况，
target>nums[n-1],return n;
target<nums[0],return 0;
那怎么判断是否存在target？返回值target
不存在：index== n||nums[index]!=target;
### 1.1闭区间
```java
private int findLowerBound(int[] nums,int target){
	int n=nums.length;
	int left=0;
	int right=n-1;
	//循环不变量，[0,left-1]均小于target
	//[right+1,n-1]均>=target
	//循环终止时，left==right+1
	//那么[0,left-1]均小于target,[left,n-1]均>=target,所以下标left是第一个>=target的下标
	while(left<=right){
		//在[left,right]闭区间上找
		
		//为什么不直接写(left+right)/2。
		//因为，left+right可能超过int范围。
		int mid=left+(right-left)/2;
		//保持循环不变式
		if(nums[mid]>=target)
			right=mid-1;//缩小区间到[left,mid-1]
		else
			left=mid+1;//缩小区间到[mid+1,right]
	}
	return left;
}
```
### 1.2开区间
```java
private int findLowerBound(int[] nums,int target){
	int n=nums.length;
	int left=-1;
	int right=n;
	//循环不变量，[0,left]均<target
	//[right,n-1]均>=target
	//循环终止时，left+1==right
	//那么[0,left(right)]均小于target,[left+1(right),n-1]均>=target,所以下标right是第一个>=target的下标
	while(left+1<right){
		int mid=left+(right-left)/2;
		//保持循环不变式
		if(nums[mid]>=target)
			right=mid;
		else
			left=mid;
	}
	return right;
}
```

```java
class Solution {
    public int hIndex(int[] citations) {
        int n = citations.length;
        int left = 1;
        int right = n;
        while (left <= right) {
            int mid = (left + right) >>> 1;
            //为什么只用citations[n - mid] >= mid就能判断？
            //citations[n-mid]:倒数第mid篇文章，如果该篇文章>=mid，就说明后面的文章引用数都>=mid,即已经有mid篇文章>=mid了。
            if (citations[n - mid] >= mid) {
                left = mid + 1; 
            } else {
                right = mid - 1;
            }
        }
        return right;
    }
}
```

# 四.二分存在
上面题型中，我们都在求>=target的最小下标，满足题意的最大/最小答案。
为什么这类题目能求最大/最小值呢？
以闭区间，求最小答案，二分排序为例（求最小相反）
其实是因为他们保证了x∈[0,left-1],check(x)== false
x∈[right+1,n-1],check(x)== true
因此，在结束循环时，left即为最小的能满足题意的答案。

那么，如果我们只是想求满足题意的某个下标呢？
可能数组不再有序，可能x∈[0,left-1],check(x)不一定均为false/true,x∈[right+1,n-1],check(x)不一定true/false。
但是，如果我们保证答案始终存在[left，right]中，循环结束，剩下来的那个数就是一个可能的答案。
那怎么缩小范围呢？
利用题目要求，找一个函数check,根据check(mid)，能直接得到答案在左边还是右边。
常见题：峰值，翻转数组，中位数。

## 例题
### 例1：寻找峰值
[寻找峰值](https://leetcode.cn/problems/find-peak-element/description/)
![[Pasted image 20260420214106.png|431]]
**思路**：
	定理：如果 i<n−1 且 nums[i]<nums[i+1]，那么在下标 [i+1,n−1] 中一定存在峰值。

证明：反证法，假设下标 [i+1,n−1] 中没有峰值。

- 由于 i+1 不是峰值且 nums[i]<nums[i+1]，所以一定有 nums[i+1]<nums[i+2] 成立，否则 i+1 就是峰值了。注意题目保证相邻元素不同，不存在相邻元素相等的情况。
- 由于 i+2 不是峰值且 nums[i+1]<nums[i+2]，所以一定有 nums[i+2]<nums[i+3] 成立，否则 i+2 就是峰值了。
依此类推，得
- nums[i]<nums[i+1]<nums[i+2]<⋯<nums[n−1]>nums[n]=−∞
这意味着 nums[n−1] 是峰值，矛盾，所以原命题成立。
- 同理可得，如果 i<n−1 且 nums[i]>nums[i+1]，那么在 [0,i] 中一定存在峰值。

所以，通过比较 nums[i] 和 nums[i+1] 的大小关系，可以直接判断答案在左半部分还是右半部分。因此用二分法解决

---
```java
class Solution {
    public int findPeakElement(int[] nums) {
        int n=nums.length;
        int left=0;
        //小技巧：right=n-2
        //1.正确性：即使right=n-2,仍不会错过n-1的答案。
        //因为结束时，left=right+1,left可能取值范围为[0,n-1](一直是left=mid+1)
        //2.不会导致数组越界问题
        //要比较nums[mid]>nums[mid+1]，如果right=n-1，mid能取到n-1,导致mid+1越界
        int right=n-2;
        while(left<=right){
            int mid=left+(right-left)/2;
            if(nums[mid]>nums[mid+1])
                right=mid-1;
            else
                left=mid+1;
        }
        return left;
    }
}
```

这样做虽然可以找到峰顶，但在最坏情况下的时间复杂度是 O(mn)，不满足题目要求。如下图，我们可能会走出一条蛇形路径。

二分解法：
![[Pasted image 20260420215601.png|530]]
**综上所述，我们可以二分包含峰顶的行号 i：

- 如果 mat[i] 的最大值比它下面的相邻数字小，则存在一个峰顶，其行号大于 i。缩小二分范围，更新二分区间左端点 left。
- 如果 mat[i] 的最大值比它下面的相邻数字大，则存在一个峰顶，其行号小于或等于 i。缩小二分范围，更新二分区间右端点 right。

```java
class Solution {
    public int[] findPeakGrid(int[][] mat) {
        int left = 0;
        int right = mat.length - 2;
        while (left <= right) {
            int i = (left + right) >>> 1;
            int j = indexOfMax(mat[i]);
            if (mat[i][j] > mat[i + 1][j]) {
                right = i - 1; // 峰顶行号 <= i
            } else {
                left = i + 1; // 峰顶行号 > i
            }
        }
        return new int[]{left, indexOfMax(mat[left])};
    }

    private int indexOfMax(int[] a) {
        int idx = 0;
        for (int i = 0; i < a.length; i++) {
            if (a[i] > a[idx]) {
                idx = i;
            }
        }
        return idx;
    }
}
```

### 例2：寻找排序数组中的最小值
#hot100 [寻找排序数组中的最小值](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260420220251.png|439]]
设 x=nums[mid] 是现在二分取到的数。

我们需要判断 x 和数组最小值的位置关系，谁在左边，谁在右边？

把 x 与最后一个数 nums[n−1] 比大小：

- 如果 x>nums[n−1]，那么可以推出以下结论：
	- nums 一定被分成左右两个递增段；
	- x 在第一段。
	- 最小值在第二段。
所以 x 一定在最小值的左边。

- 如果 x≤nums[n−1]，那么 x 一定在第二段。（或者 nums 就是递增数组，此时只有一段。）
x 要么是最小值，要么在最小值右边。

所以，只需要比较 x 和 nums[n−1] 的大小关系，就间接地知道了 x 和数组最小值的位置关系，从而不断地缩小数组最小值所在位置的范围，二分找到数组最小值。

```java
class Solution {
    public int findMin(int[] nums) {
        int n=nums.length;
        int left=0;
        int right=n-2;
        while(left<=right){
            int mid=left+(right-left)/2;
            if(nums[mid]>nums[n-1])
                left=mid+1;
            else
                right=mid-1;
        }
        return nums[left];
    }
}
```

分类讨论：

- 如果 x 和 target 在不同的递增段：

### 例3：寻找两个正序数组的中位数
#hot100 [寻找两个正序数组的中位数](https://leetcode.cn/problems/median-of-two-sorted-arrays/description/?envType=study-plan-v2&envId=top-100-liked)
![[Pasted image 20260421131143.png|401]]
**中位数定义**：
假设两数组合并后中位数下标为mid,那么整个数组被mid分成了两半，
左边为[0,mid]，右边为[mid+1,m+n-1]。

- 当m+n为奇数时，左边个数=右边个数+1.
$$
\begin{align}                                   
mid+1=m+n-(mid+1)+1  \\
mid=(m+n-1)/2；
\end{align}
$$
中位数=nums[mid]

- 当m+n为偶数时，左边个数=右边个数
$$
\begin{align}
mid+1=m+n-(mid+1) \\
mid=(m+n)/2-1;
\end{align}
$$
中位数=(nums[mid-1]+nums[mid])/2;

思路：
设左半部分由A[0...i-1]和B[0...j-1]组成，右边为A,B数组剩下来的数组成。

则i，j要满足条件：

$$  
\begin{align}
i+j=mid+1=(m+n+1)/2(m+n为奇数)\\
=(m+n)/2(m+n为偶数) \\
\end{align}
$$
$$
\begin{align}
可同一为：(m+n+1)/2
\end{align}
$$
且
$$
\begin{align}
max(A[i-1],B[i-1])<min(A[i],B[i])  
\end{align}
$$


那么，若n+m为偶数，则中位数等于（max(A[i-1],B[i-1])+min(A[i],B[i])）/2，

若m+n为奇数，则中位数等于min(A[i],B[i])。

找i，j方法：短的数组上做二分法，直到找到满足的i，j为止
