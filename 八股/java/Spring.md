# 一.Spring核心思想

## 1.IOC
### 1.1什么是IOC，为什么要IOC
**什么是IOC**
IoC （Inversion of Control ）即控制反转/反转控制。它是一种思想不是一个技术实现。描述的是：Java 开发领域对象的创建以及管理的问题。

**为什么需要IOC**
传统开发方法：手动new一个对象出来
使用IOC思想开发：不通过 new 关键字来创建对象，而是通过 IoC 容器(Spring 框架) 来帮助我们实例化对象。我们需要哪个对象，直接从 IoC 容器里面去取即可。

好处？
假设我们有很多个地方new了一个接口的实例化对象，但因为业务改动，要重新实现这个接口。那么以前代码new出来的对象都要改成新的实例化对象，代码间耦合度高，修改相当麻烦。
但如果使用IOC思想，只用把新的实例化对象给IOC容器保管，其他代码需要时，让IOC容器注入即可。不用关心到底注入的是哪个实例，代码耦合度低。
